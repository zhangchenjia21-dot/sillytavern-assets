# 4. Runtime Context Orchestration｜所有后续资产前提

冻结：

```text
Available != Enabled != Runtime Relevant != Model Visible
Full Asset != Prompt Payload
Dependency Graph != Context Inclusion Graph
```

带内部可选能力的 Package 进一步：

```text
Package Included != Feature Enabled != Module Enabled != Runtime Relevant != Model Visible
```

长期 deterministic 状态推进：

```text
Background deterministic progression != Model Activation
```

Router：

```text
Player Input
+ pruned Enabled Routing Profiles
+ minimal current context
↓
Model-first Semantic Router
↓
immediate Domain / Intent candidates
↓
Program structural validation + state-mandatory augmentation
↓
JIT bounded projection
```

后续后果通过 Formal Event / Handoff 激活，不要求 Router 预测全世界因果。

Pattern：`[[通用资产库_RuntimeContextContract模式_v0.3]]`；Contract Index：`[[通用资产库_RuntimeContextContract索引_v0.2]]`。
