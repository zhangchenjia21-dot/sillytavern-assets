# 10. Architecture Reflection

每个 Retrofit Wave / Shared Foundation Cluster 结束后执行 Future Explosion Review：

- Context 是否随无关资产增长；
- 是否出现 state mirroring；
- 是否误把依赖展开成 Prompt；
- 是否过度拆模块；
- 是否需要用户做成本 /长期体验反思。
