# 3. Runtime Context Orchestration｜新横切前提

所有后续 Core 不再只回答“我拥有哪个 Domain”，还必须回答：

> **我何时应该进入当前 Runtime / Model Working Set，以及何时不应该进入。**

冻结：

```text
Available != Enabled != Runtime Relevant != Model Visible
```

```text
Full Asset != Prompt Payload
```

```text
Dependency Graph != Context Inclusion Graph
```

Router 正式方向：

```text
Player Input
+
Enabled Expansion Routing Profiles
+
minimal scene context
↓
Model-first Semantic Router
↓
immediate Domain / Intent candidates
↓
Program structural validation
+
state-mandatory augmentation
↓
JIT bounded projection
```

后续影响由 Formal Event / Handoff 激活，不要求 Router 第一轮预测全部后果。

# 4. Generic Library Identity Normalization

仍需维护：

- 魔法基础；
- 神术与信仰；
- 战斗魔法。

目标：

- 去除首发世界作为资产身份；
- 诸界余辉保留为 reference consumer；
- blueprint 统一指向通用资产库；
- 保留真实世界兼容信息。

该维护不应打断 Shared Foundation 的 Core-first 顺序；可以在一个合适的 Generic Library Convergence 节点集中完成。

---

# 5. Generic Metadata / G9 Binding

G9 前最后一次 Semantic 收敛时，通用资产人工管理信息至少需要能表达：

- asset identity / version / status；
- library tier / dependency role；
- hard / optional / conditional；
- provider / handoff / contribution；
- reference world consumers；
- UI ownership / contribution；
- Runtime Context Contract；
- creator / asset-spec binding；
- supersedes。

这些仍是 Semantic / Authoring requirement，不是当前机器 Schema。

---

# 9. Context Composition Stress Test

G9 / Generic Library Convergence 需要建立：

```text
Typical Valid Bundle
Heavy Valid Bundle
Worst Reasonable Valid Bundle
```

检查：

- unrelated Turn context 是否随 enabled asset 数显著增长；
- transitive context explosion；
- pairwise integration explosion；
- state mirroring；
- prompt-owned deterministic mechanics；
- cost / latency / correctness 随规模变化。

核心目标：

> 长期 Game State 与资产数量可以增长，但普通 Turn 的 Model Working Set 必须保持有界。

---

# 10. Periodic Architecture Audit / User Reflection

在以下节点重新审视路线：

- Shared Foundation / Platform Core 新形成；
- 2–5 个高耦合模块形成 Cluster；
- G9 Schema / Contract Freeze 前；
- 大规模 Migration 前；
- 阶段关闭前；
- 用户主动质疑长期方向时。

审计不只找当前 Bug，还要找“规模扩大后会爆炸”的架构雷。

若涉及长期体验、成本、维护偏好或不可逆架构，Agent 先给事实与推荐，再邀请用户做项目所有者视角的阶段性反思。

---

# 11. 重新评估条件

出现以下情况立即更新本路线：

- G8 / G9 Host Capability 变化；
- Context Composition 实测证明当前投影策略不稳定；
- Shared Foundation 新 Core 完成或拆分；
- 新世界形成第二真实消费者；
- Current Theme 数量显著增加；
- Creator Asset Library Workspace 成型；
- 用户体验或成本出现非线性增长。
