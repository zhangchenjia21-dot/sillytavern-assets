# 通用拓展包资产库总蓝图 v0.5

> [!abstract] 资产库定位
> 本文件是所有跨世界可复用 Expansion Pack 的库级维护基线。
>
> 它回答：当前有哪些通用资产、谁拥有哪个 Canonical Domain、依赖怎样组织、世界如何消费资产，以及这些资产怎样通过 Runtime Context Orchestration 有界激活。

---

# 1. 顶层原则

## 1.1 Generic Expansion != World Pack

Generic Asset 描述跨世界机制语义；World Pack 负责具体世界解释、定义贡献与实例化。

世界消费 Generic Core，但不反向拥有 Generic Core。

## 1.2 独立资产身份

通用资产拥有独立 Identity / Version / Owner / Dependency / Status / Reference Consumer。

`first consumer != generic owner`。

## 1.3 Runtime 是执行权威

资产可定义 State / Rule / Intent / Resolution Semantics / Event / Handoff / Permission / UI intent / Host requirement。

资产与模型不得 Own：RNG / Dice / Program Judge / Formal Outcome / Atomic Commit / direct State Mutation / Save-Restore authority。

## 1.4 Bounded Runtime Working Set

```text
Asset Library
!= Game Enabled Asset Set
!= Current Runtime Relevant Set
!= Current Model Visible Working Set
```

```text
Full Semantic Asset != Model Prompt Payload
Dependency Graph != Context Inclusion Graph
```

长期世界状态、历史与资产数量增长，不应自动转化为普通 Turn Prompt 同比增长。

# 5. Reputation Semantic Boundary｜新增

```text
Public Reputation != Relationship Respect
Public Reputation != ORG Rank
Public Reputation != Political Recognition
Public Reputation != Legal Status
Public Reputation != Character Capability
Public Reputation != Character Knowledge
```

Reputation 可以错误、争议、过时；它记录社会如何看待 Target，不复制 World Truth。

---

# 6. Typed Relations

正式关系：Hard / Optional / Conditional / Provider→Consumer / Handoff / Contribution / Reference。

禁止 Hard Cycle、模糊 dependency、fallback second owner。

Handoff 只传 Cause / Event / Candidate / Effect / Context，不转移 Ownership。

# 7. Runtime Context Contract

所有新 Core / 重要 Expansion 必须采用：

> `[[通用资产库_RuntimeContextContract模式_v0.2]]`

至少回答：Routing Profile / Immediate Activation / State-mandatory / Downstream Activation / No-load / Minimal Read / Model-needed / Program-owned / Output Candidate / Handoff-Information Boundary / Context Cost。

## Model-first Router

```text
Player Input
+
Enabled Routing Profiles
+
minimal current context
↓
Router Model
↓
immediate Domain / Intent candidates
↓
Program structural validation + state-mandatory augmentation
↓
JIT bounded projections
```

Router 不预测全部后果；Formal Event / State Change 通过 Typed Handoff 激活下游。

# 8. Context Reference Cluster

Wave 1 + Reputation Reference 已通过 6-asset Context Cluster Audit。

冻结结论：

- 两者同时 Enabled 不要求同时 Prompted；
- ORG Target / Role 可形成 bounded projection 给 Reputation；
- Reputation 不反写 Role / Membership；
- public appointment / resignation 可通过 Event 触发下游声誉变化；
- Role / Rank 与社会 Standing 没有 duplicate owner。

Context Contract Pattern v0.2 已冻结：新资产默认正文内建；成熟旧资产在 Domain Semantics 不变时允许唯一 Sidecar Retrofit。

Canonical Contract location 由 `[[通用资产库_RuntimeContextContract索引_v0.1]]` 管理。
