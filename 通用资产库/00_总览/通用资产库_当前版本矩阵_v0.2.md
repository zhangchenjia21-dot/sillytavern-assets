# 5. Runtime Context Architecture｜库级约束

自本版本起，所有新 Core / 重要 Expansion 必须遵守：

```text
Asset Library
!= Game Enabled Asset Set
!= Runtime Relevant Set
!= Model Visible Working Set
```

```text
Full Semantic Asset
!= Model Prompt Payload
```

```text
Dependency Graph
!= Context Inclusion Graph
```

每个新资产至少在语义上声明 Routing Profile / Activation / No-load / Minimal Read / Model-needed / Program-owned / Output Candidate / Handoff / Information Boundary / Context Cost。

当前不冻结最终机器字段或 token budget。
