# 通用拓展包资产库总蓝图 v0.3

> [!abstract] 资产库定位
> 本文件是所有跨世界可复用 Expansion Pack 的库级维护基线。
>
> 它同时回答：当前有哪些通用资产、谁拥有哪个 Canonical Domain、依赖怎样组织、世界如何消费资产，以及**这些资产未来怎样被 Runtime 有界激活而不是全量塞进模型上下文**。

---

# 1. 顶层原则

## 1.1 Generic Expansion != World Pack

通用资产描述跨世界可复用机制语义；World Pack 决定具体世界为什么存在这些机制、如何解释和实例化。

世界可以消费 Generic Asset，但不能反向拥有 Generic Core。

## 1.2 独立资产身份

通用资产拥有独立 Identity / Version / Owner / Dependency / Status / Reference Consumer；first consumer 不改变 generic identity。

## 1.3 Runtime 是执行权威

资产可定义 State / Rule / Action / Intent / Resolution semantics / Event / Handoff / Permission / UI intent / Host requirement。

资产与模型不得拥有 RNG、Dice、Program Judge、Formal Outcome、Atomic Commit、直接 State Mutation、Save / Restore authority。

## 1.4 Bounded Runtime Working Set

正式冻结：

```text
Asset Library
!= Game Enabled Asset Set
!= Current Runtime Relevant Set
!= Current Model Visible Working Set
```

```text
Full Semantic Asset
!= Model Prompt Payload
```

```text
Dependency Graph
!= Context Inclusion Graph
```

长期世界状态与资产数量增长不应自动转化为普通 Turn Prompt 的同比增长。

# 5. 关系类型

正式关系：

- Hard Dependency；
- Optional Integration；
- Module Conditional Dependency；
- Provider → Consumer；
- Handoff；
- Contribution；
- Reference / Read-only。

禁止模糊 `dependency`；禁止 Hard Cycle；禁止 fallback 创建第二事实源。

Handoff 只传 Cause / Event / Candidate / Effect / Context，不转移 Ownership。

**依赖关系不得机械推导模型上下文包含关系。**

# 6. Runtime Relevance / Context Contract

从 v0.3 起，新 Core / 重要 Expansion 必须回答：

1. Routing Profile；
2. Activation；
3. No-load Conditions；
4. Minimal Read Set；
5. Model-needed Semantics；
6. Program-owned Logic；
7. Output Candidate；
8. Handoff；
9. Information Boundary；
10. Context Cost / bounded strategy。

## 6.1 Model-first Router

正式方向：

```text
Player Input
+
Enabled Routing Profiles
+
minimal scene / active context
↓
Router Model
↓
immediate Domain / Intent candidates
↓
Program structural validation
+
state-mandatory augmentation
↓
JIT bounded projection
```

Program 不重复自然语言语义路由；只验证 ID / enabled / output 合法性，并根据 authoritative active state 补充必然参与的 Domain。

## 6.2 下游激活

Router 只判断 immediate relevance。

```text
Formal Event / State Change
→ typed Handoff
→ downstream activation
```

不要求 Router 预判全部后果。

## 6.3 长期成本目标

资产库可以持续增长；Game Instance 可以启用很多资产；Runtime Database 可以积累大量历史。

但普通无关 Turn 的 Model Working Set 必须保持有界，成本主要由 Current Relevant Complexity 决定。

# 7. UI Host 原则

通用资产库不按“一个 Expansion 一个一级栏目”组织。

优先贡献已有 Surface / Player Status / Character Detail / Entity Detail / Contextual / Alert / Map Overlay。

当前不建议拥有一级 Extension Surface：

- Character；
- Health；
- Survival；
- Combat；
- Relationship；
- ORG；
- Combat Magic。

可在完整长期 Workspace 成立时拥有：

- Traveler/System → `系统`；
- Magic → `魔法`；
- Divine → `神术 / 信仰`。

未来 Politics / War 是否拥有长期 Extension Surface，由对应 Generic Core 在 G9 Host Binding 时确认。

Surface Owner 唯一；duplicate Owner → preflight incompatible。

# 10. 版本治理

Patch：stale reference、metadata、Context Contract 补齐、UI / Host requirement 说明等，不改变 Canonical Owner。

Minor：重要机制 /合法状态 / module / resolution 能力新增，但核心 Owner 不变。

Major / Major Rewrite：Owner 改变、Scope 大迁移、拆分 / 合并、依赖拓扑改变、旧语义正式退役。

# 12. Generic Library Identity Normalization

Magic / Divine / Combat Magic 仍需完成：

- 去除首发世界作为资产身份；
- 诸界余辉降为 reference consumer；
- blueprint 统一指向通用资产库。

可以在合适 Convergence 节点集中处理，不反向打断 Shared Foundation Core-first 顺序。

# 13. 维护工作流

每次新增或更新通用资产：

```text
1. 读取总蓝图 / version matrix / current planning
2. Core / Gameplay / Theme / Framework 分类
3. Owner Gap
4. Dependency typing
5. Context Contract
6. 讨论关键产品问题
7. 用户裁定
8. 正式创作 / 修订
9. Asset Audit
10. Consumer / Context Stress Test
11. 下游影响审核
12. 更新 matrix / blueprint / dependency / consumer
13. Cluster / Generic Library Convergence
14. 必要时 Architecture Reflection / Future Explosion Review
```

不能只更新单资产正文。

# 14. G9 / Stage Closure

当前仍是 Semantic Asset 阶段。

G9 前不冻结：

- 最终 JSON / Schema；
- Runtime API；
- Router API；
- Context token budget；
- Creator machine field；
- Surface ID；
- Bundle Machine Contract。

G9 重新进入：

```text
Semantic Generic Library
+
Game Host Contract
+
Runtime Context Orchestration Decision
↓
Generic Library Binding Audit
↓
Machine Mapping / Validator / Creator Authoring
↓
Context Composition Stress Test with real provider
```

当前库级结论：

```text
Stable Generic Assets = 7
Generic Supernatural Candidates = 3
Total Existing Reusable Expansions = 10
```

长期目标：

> World Pack 组合通用机制；Runtime 只按当前相关性激活最小 Working Set；世界可以越来越丰富，但模型不需要在每个 Turn 重新阅读整个世界。
