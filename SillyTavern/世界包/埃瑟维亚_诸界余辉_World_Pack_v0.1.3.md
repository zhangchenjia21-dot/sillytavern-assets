# 1. 世界身份

## 1.1 世界名称

**埃瑟维亚**

“埃瑟维亚”是现代维尔萨恩学界最通行的世界称呼。不同文化对“整个世界”的传统名称仍可不同，但国际学术、外交与位面学通常采用这一名称。

## 1.2 核心大陆

**维尔萨恩大陆**

维尔萨恩是当前资产详细建设的文明核心大陆之一。

世界明确存在：

- 其他海外大陆；
- 大型群岛；
- 极地与远海区域；
- 其他位面中的稳定居住区或前哨；
- 尚未被现代文明完整勘明的区域。

本 v0.1 不试图一次性穷尽整个星球。

## 1.3 当前纪元

**断界历 1287 年**

现代纪年以“大断裂”后的重建年代为主要世界级参考。

不同国家仍保有：

- 王朝纪年；
- 教历；
- 学院纪年；
- 地方历法；

但国际外交与学术资料通常附带断界历换算。

## 1.4 一句话定位

一个魔法已经成为文明基础设施的成熟高魔世界：普通人能够使用日常魔法与标准魔具，真正的施法者却可以触及远超常人的力量；诸神真实存在并通过神性锚点与凡人互惠；古代神凡共同进行的升格工程在大断裂中毁灭，千余年后的现代文明正在标准化、普及化与重新探索神性边界的浪潮中进入新的历史转折。

## 1.5 世界尺度

**大型开放魔法世界。**

Runtime 不应每个 Turn 高精度模拟整个大陆。

推荐：

```text
当前 Scene
→ 高精度

当前 Place / 当前关系网络
→ 关联精度

当前 Region / 重要组织
→ 趋势级精度

遥远国家 / 海外 / 位面
→ 只有真正相关时加载
```

## 1.6 默认体验基调

- 高魔，但魔法仍有因果、条件和专业门槛；
- 宏大，但普通人的人生同样完整；
- 有诸神，但凡人不是神的木偶；
- 有古代遗迹，但现代文明不是衰败废物；
- 有毁灭级魔法，但战争与政治仍有意义；
- 有预言，但没有写死的未来；
- 有黑魔法与禁术，但伦理不等于简单颜色标签；
- 有神术与宗教，但教会不天然代表神本人；
- 可以学院生活、商业经营、宗教政治、国家战争、位面探索、恋爱与日常生活；
- 不预设救世主、魔王或唯一主线。

# 2. 玩家可见世界摘要

埃瑟维亚是一个真正生活在魔法中的世界。

你可能在清晨被自动拉开的魔纹窗帘唤醒，用恒温壶烧水，让清扫扫帚在房间里自行工作；街道上的路灯以标准魔晶维持，商铺使用保鲜符柜，工匠依靠测量术具校正作品，城市入口拥有魔法安检与警示法阵。

这些东西并不意味着每个人都是法师。

大多数普通人只是会使用经过标准化的魔法产品、简单符文和少量日常术式。真正的正式施法者需要长期学习、训练、知识与适应性。高阶法师能够改变个人、建筑和战斗；大法师则可能跨越位面、施展大预言、维持城市结界，甚至在极端条件下召来足以毁灭城区的陨星。

魔法不是神赐之物。

诸神真实存在，但神术与法术是两条不同路径。法师通过知识与术式操纵世界中的超自然规律；神职者通过与神建立联系而获得神性调用权。凡人得到力量，神则获得现世中的神性锚点。

世界上最强大的宗教由誓约与庇护之神建立，其教会甚至形成了一个大陆级教权国家。但其他主要神也真实存在，死亡之神尤其无法被任何凡人真正绕开：所有真正死亡的灵魂最终都会抵达祂所在的死亡领域。

一千多年前，古代文明曾经比今天更加接近神域。

他们与部分诸神共同建设了一项足以改变凡人存在方式的“升格工程”。工程失败后，世界经历大断裂，位面被撕裂，文明毁灭，第五位古老主神也从此失去了完整稳定的存在形态。

现代文明已经重建并超越古人在许多社会领域的成就。

如今真正改变时代的，不是某个新发现的无敌法术，而是“术式标准化”：越来越多过去只能由大师凭经验完成的魔法，被转化成可以教授、复制、认证和规模使用的标准技术。

魔法正在从少数精英的神秘权力，成为整个社会的基础能力。

没有人知道这场变化最终会把埃瑟维亚带向哪里。

> **古代曾经试图跨越神凡边界。现代人正在重新走向那条路，只是这一次，他们相信自己已经更懂得代价。**

# 3. 世界最高语义原则

## 3.1 魔法不是万能因果豁免

“这是魔法”不能成为绕过世界因果的理由。

任何重要魔法结果仍必须有：

- 合法能力；
- 真实知识；
- 可行条件；
- 环境；
- 风险；
- Program-owned Formal Outcome。

## 3.2 法术目录不是行为白名单

资产中没有预设某个 Spell Definition，不代表玩家不能尝试合理的魔法行为。

但尝试：

> ≠ 已经成功创造新法术。

真正稳定、可重复、可学习的新法术需要正式研究与创建流程。

## 3.3 强大不等于自动成功

大法师可以拥有远超普通人的能力，但：

- 不自动说服 NPC；
- 不自动获得政治合法性；
- 不自动知道隐藏事实；
- 不自动穿透城市结界；
- 不自动无视敌方大法师、神术、法器或环境条件。

## 3.4 神是真实角色，不是作者视角

神：

- 有权柄；
- 有利益；
- 有性格与偏好；
- 有有限信息；
- 可能误判；
- 可能与凡人交易；
- 可能与其他神冲突；
- 不等于全知全能。

## 3.5 开放未来

世界存在：

- 趋势；
- 预言；
- 历史惯性；
- 国家计划；
- 神性利益；
- 大断裂遗产。

但不存在必须发生的唯一结局。

## 3.6 世界事实与社会解释分离

例如：

```text
World Truth：
法术与神术在更深层本体上同源。

社会解释：
学院说神术是神性接口。
教会说法师的理论无法解释神圣权柄。
民间可能认为两者完全不同。
```

社会的理解可以错误、不完整或带政治立场。

# 4. 魔法本体与基础文明规律

## 4.1 魔法的客观存在

现代学院通常把能够承载和传播魔法效应的世界基础称为：

> **灵质（Aether）**

不同地区也会使用：

- 魔力；
- 法潮；
- 灵流；
- 奥质；
- 神秘质；

等传统术语。

这些名称并不自动表示完全不同的能源。

## 4.2 施法不是单一能源消耗

一个正式法术可以同时依赖：

- 施术者自身灵质承载；
- 精神集中；
- 身体负荷；
- 法术知识；
- 术式结构；
- 咏唱、手势或符文；
- 法器；
- 魔法材料；
- 环境灵质；
- 地脉；
- 天象；
- 位面条件；
- 其他施法者。

不同法术的要求不同。

因此世界不使用“所有魔法都只是消耗 MP”作为本体解释。

## 4.3 魔法天赋

个体存在真实差异：

- 灵质感知；
- 承载强度；
- 控制精度；
- 对特定领域的适配；
- 灵魂稳定性；
- 某些血统 / 种族特性。

但：

> **天赋影响道路，不决定人生。**

低天赋者仍可能通过知识、法器、专业化和标准术式获得重要魔法能力。

高天赋者若没有训练，也不会自然成为大法师。

## 4.4 普通魔法使用者

现代城市普通居民通常能够：

- 启动标准魔具；
- 使用家庭符具；
- 配置低风险民用消耗品；
- 学习少量高度标准化日常术式；
- 按说明维护基本魔法器具。

这更接近“魔法文明素养”，不是正式法师资格。

## 4.5 职业化魔法使用

大量职业会使用魔法辅助：

- 建筑师通过测量术具和结构符文工作；
- 农业术师控制局部灌溉、虫害与土壤检测；
- 航海师使用气象与方向魔具；
- 治疗师结合医学、炼金与基础生命术；
- 士兵使用标准防护符与附魔装备；
- 商人依赖防伪、保鲜和通讯魔具；
- 调查员使用痕迹显现和证据保存工具。

非正式法师职业仍然可以高度“魔法化”。

## 4.6 正式施法者

正式施法者拥有：

- 独立理解法术结构；
- 自主准备和施展法术；
- 判断魔法风险；
- 根据环境进行有限调整；
- 继续学习更复杂术式；

的能力。

正式法师不是固定职业模板。

他们可以同时是：

- 教师；
- 军官；
- 贵族；
- 冒险者；
- 商人；
- 工匠；
- 研究者；
- 医师；
- 政治人物。

# 5. 现代魔法层级的社会理解

> [!note] 本节只描述社会尺度，不冻结未来 Expansion 的机器等级枚举。

## 5.1 日常魔法

高度标准化、低风险、普通人可以学习或使用器具完成。

## 5.2 基础与正式魔法

需要完整施法教育，构成专业施法者的大部分工作。

## 5.3 高阶魔法

对知识、控制力、准备或资源要求明显提高。

## 5.4 大师魔法

只有少数长期专业化施法者能够稳定掌握。

## 5.5 传奇魔法

已经足以影响：

- 大型建筑；
- 城市；
- 战场；
- 位面；
- 大范围环境；
- 国家级信息优势；

的术式。

## 5.6 神迹 / 神权层面

“比传奇法术更高级”并不自然等于“第十一级法术”。

当效果开始：

- 重写世界基本规则；
- 直接决定灵魂终极去留；
- 创造完整神性权柄；
- 任意修改时间因果；

时，已经进入神权或神性层面。

# 6. 术式标准化革命

## 6.1 时代核心

断界历 1287 年的埃瑟维亚正在经历一次深刻变化：

> **魔法从“只能由高手完整掌握的技艺”，逐渐成为“可以被社会拆解、复制和标准化的技术体系”。**

## 6.2 标准化的表现

现代已经逐渐出现：

- 通用符文规范；
- 标准材料纯度等级；
- 魔晶尺寸与接口标准；
- 民用法器安全认证；
- 公共建筑结界规范；
- 法术教学统一教材；
- 职业施术资格；
- 魔具维修规格；
- 魔法事故调查标准；
- 跨国术式兼容协议。

## 6.3 社会影响

标准化正在削弱：

- 古老法师家族的知识垄断；
- 大师个人经验的不可替代性；
- 部分行会的封闭技术传统。

同时催生：

- 新商人阶层；
- 魔法工厂雏形；
- 大规模民用魔具；
- 技术专利；
- 安全监管；
- 国家标准竞争；
- “魔法是不是正在被庸俗化”的文化争论。

## 6.4 尚未进入完整魔法工业时代

现代仍然缺少：

- 全自动大规模魔法生产；
- 完全可互换的高阶法器；
- 大面积无施法者维护的高阶城市系统；
- 真正普及的长距离个人传送；
- 普通家庭可负担的高阶治疗；
- 传奇魔法工业化。

因此时代属于：

> **晚期前工业文明 + 魔法工业革命前夜。**

# 7. 日常魔法生活

## 7.1 普通家庭

城市中常见：

- 魔法照明；
- 魔纹炉灶；
- 恒温水壶；
- 清扫扫帚；
- 小型保鲜柜；
- 衣物干燥符；
- 驱虫符；
- 烟火报警符；
- 门窗警示魔纹。

## 7.2 通讯

现代已有：

- 城市内部短距魔讯节点；
- 政府、军队与大型商会使用的远距通讯站；
- 昂贵的私人即时通讯法器。

但普通居民仍大量依靠：

- 信件；
- 驿运；
- 商旅；
- 公共魔讯站转递。

世界不存在所有人随时随地免费的全球即时通信。

## 7.3 交通

常见：

- 步行；
- 骑乘动物；
- 马车；
- 船舶；
- 魔法辅助车；
- 短途公共浮行平台；
- 大城市内部的固定魔导交通设施。

长距离传送仍属于高成本、高监管或高阶能力。

## 7.4 医疗

现代医疗结合：

- 解剖与普通医学；
- 炼金药剂；
- 生命魔法；
- 神术治疗；
- 康复与长期疗养。

魔法可以显著提高医疗上限，但：

- 不等于所有疾病都能治；
- 不等于普通人负担得起最高级治疗；
- 不等于真正死亡可以轻易复活。

## 7.5 教育

大型城市一般提供基础魔法文明教育：

- 魔具安全；
- 基础符文识读；
- 常见魔法事故处理；
- 简单民用术式；
- 魔法法律常识。

正式施法教育则需要更高门槛。

# 10. 阿尔瑟恩圣约国

## 10.1 国家身份

阿尔瑟恩是维尔萨恩大陆上最强大的教权国家。

其国家制度建立在第一主神**艾德拉斯**的圣约传统之上。

国家宣称：

> **文明不是自然产生的。秩序、承诺与庇护使陌生人能够共同生活，而拥有权力者必须承担维护这一秩序的责任。**

## 10.2 第一主神在国家中的地位

阿尔瑟恩并不否认其他神存在。

官方教义是：

> 艾德拉斯拥有维持文明共同秩序的最高正统权柄。

其他神可以在其对应领域受到尊重，但不得挑战圣约法对国家公共秩序的最高解释权。

## 10.3 政治结构

国家最高权力由多个机构共同构成：

- **至高圣座**：最高宗教与国家象征；
- **圣约议会**：高级神职者、地方代表和法学祭司组成；
- **大教区**：拥有明显地方行政能力；
- **圣骑士团**：承担军事、治安与神性危机处理；
- **誓约法院**：处理重大契约、教法与神圣责任案件；
- **世俗执政机构**：负责大量不需要神学裁决的日常行政。

阿尔瑟恩不是“所有官员都是牧师”。

## 10.4 教会内部派系

### 圣律正统派

强调：

- 法律；
- 教义连续性；
- 大教区层级；
- 对危险魔法的严格监管。

### 庇护改革派

强调：

> 权威存在的意义是保护人，而不是要求人服从权威本身。

支持：

- 扩大平民教育；
- 改善弱者救济；
- 限制神职贵族特权。

### 圣剑派

认为大陆进入危险时代，应加强：

- 圣骑士；
- 战争神术；
- 对第五神遗迹的封锁；
- 对危险研究的预防性打击。

### 圣约法学派

更关注：

- 神权与法律的精确边界；
- 国家与神本人是否拥有不同权利；
- 神职者能否违反教会命令却仍保有合法神术。

## 10.5 其他宗教

其他四位主要神的神殿可以合法存在，但：

- 必须登记；
- 受规模限制；
- 不能建立未经许可的独立军事组织；
- 不能宣称推翻圣约国公共法秩序。

死亡神殿尤其无法被彻底禁止，因为其葬仪与灵魂事务具有实际社会必要性。

## 10.6 优势

- 最密集的大型圣所网络；
- 高水平神术医疗；
- 强大的公共秩序；
- 本土防御神术；
- 圣骑士与神性异常处理体系；
- 高度组织化的基层教会。

## 10.7 局限

- 教会官僚可能与神本人意志偏离；
- 对标准化魔法工业态度复杂；
- 神权政治容易把政策争论包装成教义争论；
- 离开本土密集锚点网络后，其神术“主场基础设施优势”明显下降。

## 10.8 对外政策

阿尔瑟恩不认为自己有能力轻易统一整个大陆。

原因包括：

- 其他强权拥有真实战略力量；
- 神性锚点优势随距离减弱；
- 战略魔法存在报复平衡；
- 艾德拉斯的权柄是秩序与庇护，不等于“无限征服授权”；
- 大规模宗教战争会破坏其自身宣称的文明秩序。

# 11. 塞勒汀学院联邦

## 11.1 国家身份

塞勒汀不是传统意义上的单一国家。

它由：

- 七座主要学院城；
- 多个自治研究区；
- 周边普通城镇；
- 联邦议会；

组成。

## 11.2 核心价值

> **知识的权威应来自可验证的理解，而不是出生、神职或传统身份。**

这是理想，不代表现实中不存在权力垄断。

## 11.3 学院城市

学院城拥有广泛自治权，包括：

- 教学；
- 研究；
- 魔法事故处理；
- 部分司法；
- 自有护卫；
- 学术资格授予。

联邦政府处理：

- 外交；
- 战争；
- 共同货币与贸易；
- 跨城重大安全；
- 传奇级危险研究许可。

## 11.4 学术派系

存在：

- 纯理论派；
- 标准化派；
- 古代学派；
- 位面研究者；
- 神术比较研究者；
- 强伦理限制派；
- “知识不应被禁止”激进派。

## 11.5 神与学院

知识与启示之神**伊索梅尔**在塞勒汀拥有大量信徒。

但联邦坚持：

> 对知识神的信仰不能成为学术结论的替代证据。

因此这里会出现非常尖锐但合法的争论：

- 神谕能否作为论文证据？
- 神知道的东西是否天然是真的？
- 如果神不是全知，神学知识应接受怎样的验证？
- 研究神术是否构成对信仰的冒犯？

## 11.6 优势

- 大陆最高水平的魔法理论；
- 高等施法教育；
- 位面学；
- 预言学；
- 古代工程研究；
- 大量高阶法师。

## 11.7 局限

- 联邦决策慢；
- 学院利益彼此冲突；
- 危险研究事故并不罕见；
- 普通公民经常质疑“为什么法师有这么多政治自治”；
- 对真正大规模战争的组织效率不及卡尔德隆。

# 16. 五类主要智慧文明

> [!important] “五类”是文明层级的主要分类，不意味着世界只有五种智慧生命。

## 16.1 人类

人类是维尔萨恩人口最多的单一智慧种族。

其主要特征不是“平均”，而是：

- 人口规模大；
- 文化差异巨大；
- 适应多种环境；
- 各类魔法道路都有大量实践者；
- 制度变化速度较快。

不存在统一“人类文化”。

## 16.2 瑟林｜长生种

瑟林平均寿命约为人类的三至五倍。

其灵魂—灵质结构具有较强长期稳定性，使其在：

- 精密控制；
- 长期研究；
- 跨世代法术项目；
- 记忆传统；

方面具有真实优势。

### 社会影响

长寿意味着：

- 人口增长慢；
- 成熟期较长；
- 一个政治错误可能被当事人记住数百年；
- 家族与导师关系持续时间远超人类；
- “快速改革”往往带来巨大世代冲突。

### 不变量

- 瑟林并非人人是法师；
- 不天生道德高尚；
- 不拥有统一政治立场；
- 人类仍可能成为比大多数瑟林更强的法师。

## 16.3 赫姆拉｜地脉与物质亲和种

赫姆拉拥有特殊的身体与感知结构，能够更敏锐感知：

- 矿物内部应力；
- 地脉灵流；
- 魔法材料杂质；
- 大型法阵结构稳定性。

因此历史上在：

- 建筑；
- 符文；
- 矿业；
- 法器材料；
- 大型魔法工程；

领域拥有强大传统。

### 社会差异

他们并不统一生活在地下，也不等同于“铁匠种族”。

现代赫姆拉同样可以成为：

- 学者；
- 商人；
- 神职者；
- 政治人物；
- 战争法师；
- 航海者。

## 16.4 界裔｜位面来源文明类别

“界裔”是现代国际社会对多个与非物质位面拥有祖源联系的稳定智慧血脉的统称。

不同界裔之间外形、文化和身体差异可以很大。

共同点主要是：

- 对位面边界更敏锐；
- 部分身体结构适应特殊灵质环境；
- 历史上与位面迁徙存在联系。

### 不变量

界裔：

- 不自动会传送；
- 不自动了解所有位面；
- 不被视为“外来怪物”；
- 已在维尔萨恩建立延续数百年的本地社会。

## 16.5 灵造民｜魔法生命文明

灵造民不是单一生物学种族。

它是一个现代政治、法律与伦理类别：

> **由魔法创造、孕育或演化，却表现出持续人格、自我意识、独立目标和社会关系的智慧存在。**

可能包括：

- 古代构装生命后裔；
- 自主魔法核心；
- 法潮自生人格；
- 人工灵体；
- 某些脱离原术式后形成完整主体的自我意识法术生命。

### 核心社会问题

- 创造者是否拥有其所有权？
- 灵造民是否有灵魂？
- 是否可以继承财产？
- 是否可以成为神职者？
- 是否可以拥有专利和创造新的灵造生命？
- 摧毁一个灵造民属于财产损坏还是杀人？

### World Truth

至少部分灵造民**确实拥有可以被灵魂魔法与死神体系识别的完整灵魂**。

这已经推翻“人工创造的生命必然没有灵魂”的传统教义。

但灵魂究竟怎样在人工生命中产生，仍然是未解问题。

# 17. 诸神总则

## 17.1 神性权柄

神与普通高阶施法者的本质差异在于：

> **神拥有神性权柄，而不仅仅拥有巨大的能量。**

权柄使神与某些世界概念、规律、神域和锚点建立本质性关系。

## 17.2 神不是魔法创造者

魔法在诸神之外同样存在。

法师完全可以不信神而施法。

神术也不是简单“另一系法术”。

## 17.3 法术与神术同源

后台 World Truth：

> 法术与神术最终都通过同一个世界超自然本体发挥效果，但神术通过神性权柄与连接访问这一层面，法术则通过凡人的理解、术式与操纵能力访问。

这不意味着法师练得足够强就自动获得神术。

## 17.4 神性连接是一种互惠关系

凡人得到：

- 神术；
- 神职能力；
- 某些神性感知；
- 圣礼执行权。

神得到：

- 个人锚点；
- 圣所网络；
- 信仰锚点；
- 更稳定的物质世界投射。

## 17.5 教会不是神的同义词

教会：

- 可以误解神；
- 可以内部斗争；
- 可以腐败；
- 可以产生优秀制度；
- 可以宣称某政策代表神意，却未必得到神本人明确支持。

神职者违反教会命令，也不自动失去神性连接。

# 18. 第一主神：艾德拉斯｜圣约之主

## 18.1 权柄

- 秩序；
- 誓约；
- 庇护；
- 文明共同体；
- 合法责任。

## 18.2 人格方向

艾德拉斯并非温柔慈父，也不是冷酷暴君。

祂最核心的价值是：

> **承担。**

祂重视：

- 说出口的承诺；
- 拥有权力者承担对应义务；
- 强者对弱者提供真实庇护；
- 公共秩序不应因个人任性轻易毁坏。

祂厌恶：

- 空洞誓言；
- 借规则之名逃避责任；
- 只要求服从、不承担庇护义务的权威。

## 18.3 与阿尔瑟恩的关系

艾德拉斯认可阿尔瑟恩作为强大的圣约锚点体系。

但：

> **祂没有向凡人保证阿尔瑟恩政府永远正确。**

这正是圣约国神学政治最危险也最重要的张力。

## 18.4 直接觐见

最典型路径是：

> **具有世界级重量的真实圣约。**

例如：

- 结束长期大战的神圣和平；
- 一位统治者以自身未来为代价承担庇护责任；
- 两个敌对文明建立不可轻易违背的共同誓约。

真正觐见艾德拉斯的人，往往不是“祈祷更虔诚”，而是已经把自己放进一个无法轻易退出的承诺之中。

# 19. 第二主神：瑟芙拉｜万生之母

## 19.1 权柄

- 生命；
- 生长；
- 自然；
- 生育；
- 康复；
- 生态循环。

“万生之母”是常见尊称，不表示祂在所有文化中都被理解为女性人格。

## 19.2 人格方向

瑟芙拉重视：

- 生命延续；
- 生态完整；
- 新生与恢复；
- 生命在环境中的真实位置。

祂不是“永远反对死亡”的神。

在祂看来：

> 死亡本身也是生命循环的一部分。

因此瑟芙拉与死神摩尔甘之间并非天然敌对。

## 19.3 教会

瑟芙拉信仰极其广泛，却高度分散。

常见组织：

- 乡村祭司；
- 医疗修会；
- 生育与育儿圣所；
- 森林守护者；
- 生态修复团体。

其普通信徒总量可能不低于艾德拉斯，但政治集中度远低于圣约教会。

## 19.4 直接觐见

可能发生于：

- 原初生命圣地；
- 濒临灭绝物种的最后生机；
- 规模巨大的生命复苏；
- 创造一种真正新生命形式；
- 修复被魔法灾难彻底破坏的生态循环。

与祂交易的“代价”常常不是财富，而是：

> **恢复另一处被破坏的生命循环，或者放弃一种对生命整体造成不可接受伤害的利益。**

# 20. 第三主神：伊索梅尔｜藏识者

## 20.2 人格方向

祂更接近：

> **知识必须被真正理解，而不是仅仅拥有。**

祂既可能奖励求知，也可能拒绝：

- 只想获得力量却不理解后果的人；
- 把真相当作政治装饰的人；
- 无法承担答案的人。

## 20.3 与学院的关系

塞勒汀大量学者信奉伊索梅尔。

但学院普遍坚持：

> 神谕是信息来源，不是免于验证的最高论证。

因此伊索梅尔神职者与世俗学者之间既合作又冲突。

## 20.4 直接觐见

最著名的传说是：

> **用知识换知识。**

若凡人想向伊索梅尔询问真正重要的秘密，祂可能要求对方提供：

- 一个祂尚不知道的事实；
- 一个从未被正确提出的问题；
- 一个只有求问者能够证明的真相；
- 放弃某项知识的独占权。

由于神并非全知：

> **凡人掌握神不知道的信息是真实可能的。**

# 21. 第四主神：摩尔甘｜终庭之主

## 21.1 权柄

- 死亡；
- 灵魂；
- 终结；
- 安息；
- 死者秩序。

## 21.2 世界地位

任何人可以一生不信奉艾德拉斯、瑟芙拉或伊索梅尔。

但：

> **没有凡人能够永远绕开摩尔甘。**

所有真正死亡并完成渡界的灵魂最终都会抵达祂所在的死亡领域——**终庭**。

这使摩尔甘在绝大多数文明中同时：

- 令人恐惧；
- 受到尊敬；
- 很少拥有最大规模的日常信徒；
- 却几乎拥有最普遍的葬仪影响。

## 21.3 人格方向

摩尔甘并不热爱杀戮。

祂重视的是：

> **一个结束真的成为结束。**

祂尤其厌恶：

- 灵魂奴役；
- 无休止阻止死者完成死亡；
- 将有自我意识的死者当作无主资源；
- 破坏死亡秩序却拒绝承担后果。

## 21.4 亡灵立场

摩尔甘不把一切亡灵术都视为同样邪恶。

祂的神职者会区分：

- 无人格尸体构装；
- 残魂；
- 完整死者灵魂；
- 自生亡灵生命；
- 主动选择不死转化的个体。

真正严重的禁忌通常来自：

> **对完整灵魂自主性的侵犯。**

## 21.5 直接觐见

所有死者最终都有机会面对摩尔甘，但绝大多数是在已经无法返回现世的状态下。

活人主动进入终庭则属于传奇行为。

与摩尔甘直接交涉最著名的原因是：

> **复活一个已经抵达终庭的人。**

后台 World Truth：

维阿托尔：

- 没有保持普通神那样的完整人格；
- 神性在大断裂中被撕裂并与位面边界发生深层结合；
- 部分古代门、断界点、界隙与神性碎片之间存在真实联系。

## 22.3 现世接触

中接触其碎片。

没有人能够轻易证明：

# 23. 神性连接与教会世界规则

## 23.1 建立连接

神职者不是靠学习法术“学会神术”。

真正神性连接需要：

- 神与凡人之间形成真实关系；
- 对应权柄的适配；
- 信仰、圣礼、契约、经历或其他真实建立过程；
- 神愿意允许该连接存在。

具体机制归神术 Expansion。

## 23.2 连接后的自主调用

一旦连接稳定建立：

> 神职者可以在授权范围内相对稳定、自主地使用神性力量。

神不逐次审批：

- 每一次治疗；
- 每一次祝福；
- 每一次神术攻击。

## 23.3 授权范围

连接存在：

> ≠ 拥有该神全部权柄。

一个普通祭司不会因为侍奉艾德拉斯就能发动国家级神罚。

## 23.4 断契

神可以主动收回连接。

但这通常需要：

- 真实背叛；
- 破坏核心圣约；
- 神主动改变意志；
- 神性冲突；
- 外力切断锚点。

不应因：

> “神职者今天违反教会一条普通纪律”

自动失去全部神术。

## 23.5 异端仍可能拥有神术

存在真实可能：

> 教会宣布某神职者为异端，但神本人没有断开连接。

这类事件往往构成巨大宗教政治危机。

# 24. 灵魂、死亡与复活

## 24.1 灵魂是世界事实

灵魂客观存在。

现代魔法与神术能够在一定程度上：

- 感知；
- 保护；
- 伤害；
- 追踪；
- 暂时锚定；

灵魂。

但“灵魂究竟是不是完整人格”仍有学术与神学争议。

## 24.2 阶段一｜离体

肉体真正死亡后，灵魂首先离体。

这一阶段：

- 灵魂仍与肉体和现世有较强因果联系；
- 极高阶复活法术或神术仍可能直接召回；
- 时间、死亡方式、灵魂状态会改变难度。

## 24.3 阶段二｜渡界

灵魂逐渐被死亡秩序牵引离开物质世界。

此时想复活已经可能需要：

- 追踪灵魂；
- 阻断渡界；
- 灵魂锚定；
- 极高阶法术 / 神术。

## 24.4 阶段三｜终庭

当灵魂真正抵达摩尔甘所在的终庭：

> **凡人自己的法术或神术无法再单靠自身力量强行完成复活。**

从此复活必须：

1. 触及死亡神权；
2. 获得摩尔甘回应；
3. 与祂请求、谈判或交易；
4. 取得死者归还许可；
5. 再满足肉体 / 容器 / 灵魂回归等现实条件。

## 24.5 复活代价

摩尔甘没有公开“复活价格表”。

可能接受的代价可以是：

- 修复某个严重死亡秩序错误；
- 归还一个被非法扣留的灵魂；
- 承担一项长期义务；
- 放弃某个本不应被凡人拥有的死亡权柄；
- 完成只有求复活者有能力完成的任务；
- 交换一项世界级重要利益。

代价必须符合：

- 死神权柄；
- 当前因果；
- 被复活者的世界意义；
- 交易双方真实利益。

## 24.6 一般人不值得“深度复活”的含义

这不表示普通人的生命价值较低。

而是：

> **从终庭取回一个已经完成死亡的人需要极其强大的力量、关系、资源和代价。**

一个普通家庭通常不可能拥有这样的能力。

历史上真正深度复活往往已经是：

- 王朝事件；
- 教会传奇；
- 大法师人生转折；
- 世界级神迹。

# 25. 亡灵世界事实

## 25.1 “亡灵”不是单一类别

社会统称至少包含：

### 尸体构装型

尸体作为魔法材料驱动，没有原死者完整人格。

### 残魂型

死亡留下的不完整意识、记忆或情绪碎片。

### 完整灵魂型

死者完整人格仍被锚定、召回或囚禁。

### 自生亡灵型

从死亡灵质环境中自然产生的新生命，并非某个死者复活。

### 主动不死转化型

活人主动改变自身存在方式，以特殊不死形态维持人格连续性。

## 25.2 伦理差异

使用尸体：

> 不自动等于奴役灵魂。

召回完整死者并强迫服从：

> 属于严重人格和灵魂侵犯。

不同国家法律会进一步形成不同规定。

# 26. 黑魔法、禁术与社会分类

## 26.1 黑魔法是社会词汇

现代人普遍使用：

- 黑魔法；
- 邪术；
- 禁术；
- 亵渎术；

等词。

但 Runtime / 资产不应维护简单：

```text
black_magic = evil
```

## 26.2 更精确的危险维度

某项魔法可以因为以下理由被视为黑魔法：

### 本体危险

- 持续灵质污染；
- 无法控制的位面腐蚀；
- 对施术者产生结构性破坏。

### 伦理危险

- 强制精神控制；
- 灵魂奴役；
- 活体祭献；
- 非自愿人格修改。

### 公共安全危险

- 大范围毁灭；
- 未许可位面召唤；
- 城市级传送门；
- 战略预言窃取。

### 法律 / 政治禁止

某国可能禁止：

- 特定亡灵研究；
- 私人跨国传送；
- 未登记预言服务；
- 某些与第五神相关的古代术式。

这些不必全部属于宇宙意义上的邪恶。

# 27. 已知位面宇宙

> [!important] 位面机制的正式运行由未来位面类 Expansion / Runtime 负责。本节只定义 WP-01 的世界事实。

## 27.1 现世｜物质界

埃瑟维亚文明生活的主要物质世界。

## 27.2 灵海｜原生灵质位面

现代学界认为灵海与大量自然魔法现象、地脉和灵质循环存在深层关系。

它不是简单“魔力电池世界”。

其环境对普通物质生命极不友好。

## 27.3 终庭｜死亡领域

摩尔甘神权最稳定的领域。

所有完成死亡渡界的凡人灵魂最终都会抵达这里。

终庭不是传统意义上的刑罚地狱。

其更接近：

> **死亡完成之后的神权秩序领域。**

终庭深处真正发生什么，连活着的大法师和普通神职者都无法完整确认。

## 27.4 神域群

主要神拥有与自身权柄紧密联系的神性领域。

它们并非必须是传统空间意义上的“一个国家大小的位面”。

不同神的神域存在方式可以不同。

## 27.5 元域群

现代学者确认存在多个与基础物质 / 能量规律高度偏置的位面区域。

例如：

- 高热与燃烧占绝对优势的环境；
- 极端流体灵质环境；
- 高风与低重力区域；
- 高密度晶质世界。

未来 Theme Expansion 可以进一步扩展。

## 27.6 梦幕

与：

- 梦境；
- 意识；
- 记忆；
- 心灵投射；

高度相关的特殊位面层。

对其到底是“客观位面”还是“群体意识形成的世界”仍有学术争论。

## 27.7 界隙

位面之间的边界空间。

大断裂之后界隙中存在大量：

- 不稳定门路；
- 古代设施残骸；
- 维阿托尔神性碎片；
- 无法归属任何已知位面的异常区域。

## 27.8 未知位面

现代文明承认：

> 已知位面地图不完整。

发现一个真正的新位面仍然可能成为改变一个时代的学术与政治事件。

作为常规世界结构。

# 28. 预言与因果未来

## 28.1 预言是真的

预言不是纯粹心理暗示。

预言观察的是：

- 当前因果趋势；
- 未来概率；
- 条件分支；
- 高度汇聚节点。

## 28.3 汇聚节点

某些事件在大量可能未来中都出现。

例如预言可能表明：

> 某座首都在十年内极大概率经历决定国家命运的危机。

“危机”高度汇聚。

但：

- 危机原因；
- 参与者；
- 结果；
- 城市是否毁灭；

仍可能改变。

- 信息；
- 行动；
- 资源；
- 时间；
- 传奇能力；
- 世界政治变化。

因此“改变预言”本身可以成为世界级因果事件。

## 28.5 观察改变被观察未来

一项预言被公开后：

- 国家会准备；
- 人会逃避；
- 敌人会利用；
- 神会回应；

因此预言信息本身成为未来因果的一部分。

# 29. 古代文明

## 29.1 前断界文明

大断裂以前的核心文明通常统称：

> **旧辉纪文明**

它并非单一帝国，而是多个高魔国家、学院、神性组织和位面城市组成的文明体系。

现代人容易把整个古代简化成一个统一“古代魔法帝国”，这是错误的历史想象。

## 29.2 古代优势

旧辉纪在以下领域达到现代难以复制的高度：

- 个体传奇施法；

- 大型神性工程；
- 人工智慧生命；
- 灵魂研究；
- 传奇法术。

古代魔法高度依赖：

- 少数大师；
- 大型专有设施；
- 封闭知识体系；
- 强大的个人施法者；
- 神性组织。

普通人的魔法普及、标准化教育和安全体系并不一定优于现代。

## 29.4 现代超过古代的领域

现代已经在：

- 基础魔法教育；
- 民用魔具；

- 工程安全；

方面远超旧辉纪。

# 30. 大断裂｜公开历史

## 30.1 公认事实

约一千三百年前，旧辉纪文明发生世界级灾难。

后果包括：

- 多座古代城市毁灭；
- 大量位面门失控；
- 部分地区永久成为断界区；
- 诸神现世活动发生重大变化；

- 大量传奇知识失传；
- 贸易、政府和跨位面网络崩溃；
- 人口与文明大规模倒退。

古代法师进行了规模超过世界承载能力的魔法实验。

诸神之间发生战争，凡人文明被卷入。

维阿托尔试图打开不应被打开的门。

古代试图让凡人大规模获得神性，最终失控。

# 31. 大断裂｜后台 World Truth

> [!danger] **GM / Runtime Hidden World Truth**
> 本节不应默认进入普通玩家角色知识。

## 31.1 真正目标

旧辉纪晚期，部分最高级法师、神性研究者与多位主神共同推进：

> **“诸界升格网络”**

现代学界尚不知道其正式古代名称是否就是这个词。

工程目标：

1. 让凡人不必依赖极少数天赋就能稳定接触神性层级；
2. 让传奇魔法获得更稳定的世界基础；
3. 让神摆脱对传统大规模信仰体系的部分依赖；
4. 建立神、凡人、位面之间新的共享锚定结构；
5. 最终形成一种“神性开放文明”。

## 31.2 为什么神参与

神并非免费帮助凡人。

工程若成功：

- 神的现世投射会更稳定；
- 神性锚点效率提高；
- 神可以在不依赖庞大教会的情况下维持更广泛影响；
- 神的权柄可能获得跨位面扩展。

## 31.3 为什么凡人参与

凡人希望：

- 突破寿命与能力上限；
- 普及传奇魔法；
- 摆脱血统与极少数天赋的垄断；
- 进入更高位面文明；
- 甚至获得新的存在形式。

## 31.4 工程并非必然失败

后台 World Truth：

> **工程在理论上存在成功可能。**

古代研究已经解决了绝大多数能量、位面和锚定问题。

真正没有解决的是：

> **如何在共享神性结构中保持每个个体灵魂的独立边界。**

## 31.5 灵魂汇聚问题

工程最后阶段开始出现：

- 参与者记忆交叠；
- 人格边界模糊；
- 多人共享感知；
- 个体灵魂向巨大共同神性结构聚合；
- 某些参与者将这种状态描述成“终于超越孤立自我”。

这使古代阵营分裂。

一方认为：

> 这是文明升格的真正完成形态。

另一方认为：

> 这是以升格之名消灭每个人作为独立主体。

## 31.6 第五神的选择

维阿托尔早期是升格工程的重要推动者之一。

祂相信：

> 门的意义就是允许存在跨越自身边界。

但最终阶段，祂判断灵魂汇聚已经突破可接受界限。

祂参与强制切断诸界升格网络。

## 31.7 为什么切断造成灾难

升格网络已经与：

- 位面门；
- 城市灵质系统；
- 神性锚点；
- 大量参与者灵魂；
- 古代基础设施；

深度耦合。

无法安全关闭。

维阿托尔以自身神性作为关键断裂媒介。

结果：

- 神性网络崩溃；
- 位面通道撕裂；
- 大量城市系统同时失效；
- 部分参与者灵魂被毁坏或卡在异常状态；
- 维阿托尔神性被分裂并嵌入位面边界；
- 其他主神受到程度不同的反噬；
- 世界避免了全面灵魂汇聚，却付出文明毁灭代价。

## 31.8 没有单一反派

- 古代法师不是单纯疯子；
- 参与诸神不是单纯欺骗凡人；
- 维阿托尔不是简单救世主；
- 支持继续升格的人也并非全部邪恶。

大断裂的核心悲剧是：

> **一个真实可能改变文明的伟大计划，在最后一步暴露出“力量与人格独立无法同时保证”的致命缺口。**

## 31.9 现代真正危险的秘密

部分现代研究已经再次接近古代问题。

如果能够解决：

> **共享神性与个体灵魂边界兼容**

那么升格工程理论上仍可能重新开始。

此事实不得自动成为普通玩家开局知识。

# 34. 战略魔法与国际秩序

## 34.1 传奇毁灭魔法真实存在

例如陨石类法术如果成功完成，可以造成真正灾难级破坏。

不能为了世界平衡把它定义成：

> “对一个敌人造成较高伤害。”

## 34.2 战略施法为什么没有终结战争

### 准备

真正战略法术可能需要：

- 数小时至数日；
- 大型法阵；
- 稀有材料；
- 辅助施法者；
- 特定天象 / 位面条件。

### 可侦测

大规模灵质聚集往往能够被：

- 预警塔；
- 敌方大法师；
- 神术；
- 魔法情报机构；

发现。

### 城市防御

主要城市拥有：

- 战略结界；
- 空间锁；
- 应急偏转系统；
- 反制节点。

它们不能保证无敌，但显著提高攻击成本。

### 施法者风险

进行传奇仪式的大法师可能成为：

- 刺杀目标；
- 反制目标；
- 突袭目标；
- 位面干扰目标。

### 报复

敌国可能拥有：

- 对等大法师；
- 神术；
- 战略法器；
- 暗杀网络；
- 同盟。

## 34.3 《奥维斯塔禁毁协约》

五强与多个重要小国共同签署的国际协议。

核心原则包括：

- 不首先对大型无防御人口中心使用毁灭级传奇法术；
- 禁止故意破坏可能引发跨国位面灾难的关键结构；
- 禁止大范围灵魂武器；
- 保护部分国际中立魔法设施；
- 重大传奇施法事故必须进行国际通报。

## 34.4 协约不是世界魔法规则

国家可以：

- 违反；
- 退出；
- 秘密绕过；
- 对条款产生不同解释。

真正的平衡来自：

> **成本 + 反制 + 报复 + 政治后果 + 神性后果。**

# 39. 魔法教育体系

## 39.1 多轨并存

正式魔法教育包括：

- 大学 / 学院；
- 私人师徒；
- 贵族与家族传统；
- 工匠行会；
- 军事学院；
- 神学院；
- 地方传统；
- 自学与远程课程。

## 39.2 学院不是唯一合法道路

学院学位证明：

- 一种教育背景；
- 某些标准知识；
- 合格安全训练。

但不能证明：

> 非学院传统天然低等。

## 39.3 普通教育

基础学校通常不训练学生成为法师，但会教授：

- 魔法安全；
- 基础灵质常识；
- 日常魔具；
- 简单标准符文；
- 法律禁忌。

# 40. 宗教与普通社会

## 40.1 信仰不等于神术

大量普通人：

- 信神；
- 参加祭礼；
- 尊重神殿；

但没有建立可调用神术的正式神性连接。

## 40.2 无神论 / 不敬神

神客观存在，所以严格“神不存在论”在现代属于非常边缘的思想。

但可以存在：

- “神存在但不值得崇拜”；
- “神只是拥有特殊权柄的高阶生命”；
- “凡人不应依赖神”；
- “神性本质最终也可以被科学解释”；

等世俗或反神权立场。

## 40.3 神与道德

世界不采用：

> 某神 = 绝对善、某神 = 绝对恶

作为简单宇宙阵营表。

神的权柄、人格与利益可以与凡人道德判断发生冲突。

# 41. 魔法生命与人格权利

## 41.1 现代争论

灵造民权利是现代最重要社会议题之一。

主要立场：

### 人格派

只要存在：

- 自我意识；
- 持续人格；
- 自主目标；
- 社会关系；

就应拥有完整人格权。

### 灵魂派

认为必须证明存在真正灵魂。

### 创造权派

认为创造者拥有一定所有权或控制权。

### 危险监管派

认为部分灵造生命拥有超常能力，需要特殊法律身份。

## 41.2 World Truth

至少部分灵造民确实拥有灵魂。

但：

> “拥有灵魂的充分条件是什么”仍未知。

## 41.3 国家差异

- 奥维斯塔与弥拉泽相对开放；
- 塞勒汀学界存在深入研究；
- 阿尔瑟恩神学内部正在重新解释传统教义；
- 卡尔德隆承认部分人格权，但要求高风险灵造个体登记；
- 瓦尔瑟兰不同领地差异很大。

## 43.1 三层信息

```text
World Truth
≠
```

## 43.2 普通公开常识

一般受教育居民可能知道：

- 五强；

- 魔法日常常识；

需要专业背景才能知道：

- 复杂位面结构；
- 高阶预言理论；
- 战略结界细节；
- 神性锚点精确理论；
- 大断裂最新考古证据；
- 某些灵魂研究结论。

## 43.4 后台隐藏 World Truth

普通玩家角色开局不得自动知道：

- 诸界升格网络的完整真实目标；
- 灵魂汇聚已经接近发生；
- 维阿托尔主动参与切断；
- 工程理论上仍可能成功；
- 四位现代主神各自在古代工程中的详细参与程度；
- 哪些现代机构已经重新接近关键技术。

神并不自动拥有全部 World Truth。

尤其：

- 某些凡人秘密；
- 其他神的私密计划；
- 第五神不同碎片的全部状态；
- 未来所有分支；

可能不在某神知识中。

# 44. 五神与大断裂的隐藏参与边界

> [!danger] Hidden GM / Runtime Truth

## 44.1 艾德拉斯

曾支持建立更稳定神性锚点，但对最终阶段灵魂边界风险持保留意见。

## 44.2 瑟芙拉

最早发现共享结构正在改变独立生命主体之间的界限，是后期反对继续扩大实验的重要力量之一。

## 44.3 伊索梅尔

掌握大量核心理论，但其真正责任存在灰色地带：

> 祂知道的危险是否比公开承认的更多？

此项可以保持部分未定义，不在 v0.1 写死最终道德裁决。

## 44.4 摩尔甘

从一开始就反对任何可能让灵魂无法正常完成独立死亡的结构。

但祂并没有一开始阻止整个计划，因为工程早期确实允许更稳定的灵魂保护与死亡过渡研究。

## 44.5 维阿托尔

既是升格计划的重要推动者，也是最终切断者。

这使祂成为最难用“英雄 / 罪人”分类的神。

# 45. 世界趋势｜断界历 1287

> [!note] 趋势不是预写剧情，也不是一定会发生的 Event。

## 45.1 标准化浪潮

弥拉泽、卡尔德隆与塞勒汀正在推动不同版本的术式标准。

未来谁的标准成为大陆主流，将影响：

- 商业；
- 教育；
- 军事；
- 法器；
- 国家权力。

## 45.2 圣约国改革争论

阿尔瑟恩正在争论：

- 神权国家如何面对越来越世俗化的魔法社会；
- 教会是否应该扩大公共教育；
- 是否允许更自由研究神术本质。

## 45.3 灵造民权利

多个国家即将讨论新的灵造民人格法案。

没有预设必然结果。

## 45.4 位面探索复兴

现代安全技术使部分古代门再次可以被研究。

新位面发现与古代路线恢复可能改变国际格局。

## 45.5 大断裂研究升温

多个机构发现：

> 古代升格系统的部分技术并没有彻底失效。

该信息尚未成为普通公开常识。

## 45.6 战略魔法军备竞争

五强都公开支持奥维斯塔禁毁协约。

同时都在：

- 更新城市结界；
- 训练战略施法者；
- 研究反制；
- 建立情报网络。

## 45.7 第五神碎片异常

最近数十年，部分古代门与断界区出现更频繁的维阿托尔神性回声。

原因未知。

这不是预设“第五神即将复活”。

# 46. 开放矛盾

世界应长期支持：

- 魔法精英 vs 魔法普及；
- 教权 vs 世俗研究；
- 国家安全 vs 学术自由；
- 血统传统 vs 平民教育；
- 技术专利 vs 公共魔法；
- 灵造民人格权；
- 死亡秩序 vs 复活欲望；
- 预言信息 vs 自由选择；
- 大断裂禁忌 vs 文明升格梦想；
- 神的利益 vs 凡人的利益；
- 国际战略威慑 vs 新传奇魔法；
- 位面探索利益 vs 世界安全。

任何一个都可以成为一局游戏的重要主题。

没有一个必须成为所有游戏的主线。

# 49. 玩家不是世界自动中心

## 49.1 普通身份

普通学生不会自动进入国家机密研究。

普通商人不会自动见到至高圣座。

普通冒险者不会因为是玩家就获得大法师尊重。

## 49.2 高阶身份

高阶身份会自然获得：

- 更多社会入口；
- 更大责任；
- 更复杂敌友网络；
- 更高失败成本。

## 49.3 传奇身份

传奇人物本来就会改变世界对其行为的反应。

但：

> 影响力不是剧情保护。

国家仍可能：

- 防备；
- 联合制衡；
- 招揽；
- 暗杀；
- 公开谈判。

# 50. 神与玩家代理权

## 50.1 神谕不能替玩家决定

即使神说：

> “你应该杀死他。”

这仍然只是：

- 神的要求；
- 神的立场；
- 世界信息。

不能自动变成玩家角色已决定执行。

## 50.2 预言不能替玩家决定

“预言你将成为国王”不能自动修改：

- 玩家目标；
- 玩家欲望；
- 玩家未来行动。

## 50.3 精神魔法不能重写玩家过去

外来精神影响可以形成真实状态或约束，但不得偷偷声明：

> “你其实一直爱某人 / 一直效忠某国。”

除非这本来就是玩家 Character Definition 或合法已提交世界事实。

# 51. 世界知识与 Character Knowledge

## 51.1 世界知道，不代表角色知道

例如后台确定：

> 第五神是最终切断升格网络的重要参与者。

普通角色只可能知道：

> 第五神与大断裂有关，具体责任存在争议。

## 51.2 神知道，不代表神职者知道

神职者与神连接：

> ≠ 自动下载神的全部记忆。

## 51.3 专业背景影响知识

角色可能因身份获得：

- 学院知识；
- 神学知识；
- 国家机密；
- 商业知识；
- 遗迹知识；
- 位面知识。

这些必须进入 Character Knowledge / Game State，而不是由叙事自由调用。

# 52. Character Card 引用规则

## 52.1 World Pack 不复制完整人物人格

未来重要 NPC 采用独立 Character Card。

World Pack 可以引用：

- 国家公开职位；
- 公开历史角色；
- 与世界事件的最小关系。

但不保存：

- 完整人格；
- 私密目标；
- 详细关系网；
- 所有秘密；
- 当前 Game State。

## 52.2 神暂不使用普通 Character Card

五位主神第一阶段继续由 World Pack 定义其世界级神性主体。

若未来 Runtime 需要神作为正式可交互 Character Definition，应单独裁定神性角色模型。

不能为方便聊天把神降格成普通 NPC Card。

# 53. Expansion Pack 语义挂点

> [!warning] 本节是人工创作接口，不是假装已经存在的机器依赖字段。

## 53.1 魔法基础

World Pack 提供：

- 魔法世界事实；
- 社会教育；
- 法术普及背景；
- 国家法律环境。

Expansion 提供：

- 标准施法机制；
- 基础 Spell Definitions；
- 法术掌握与学习。

## 53.2 Theme Expansion 与 Legendary Grade

World Pack 提供：

- 传奇魔法客观存在；
- 战略社会背景；
- 大法师尺度；
- 国际条约；
- 当前世界中哪些组织、遗迹、人物真正拥有某些 Legendary Spell 知识。

`EP-MAGIC-CORE｜魔法基础` 提供：

- Legendary Qualification；
- 传奇知识可获得性语义；
- 传奇学习共同门槛；
- 传奇施法共同 Grammar。

具体 Theme Expansion 提供：

- 本领域正式 Legendary Spell Definition；
- 本领域专属 Requirement / Interaction。

因此：

> 大预言、位面传送、陨石类魔法等不会因为“很强”而集中进入一个独立《传说魔法》包。

## 53.3 神术与信仰

World Pack 提供：

- 五神；
- 权柄；
- 教会；
- 神性锚点世界事实；
- 觐见方式背景。

Expansion 提供：

- 连接；
- 授权；
- 神术；
- 断契；
- 多神连接；
- 神性状态与 Action。

## 53.4 法术研究与创造

World Pack 只确认：

> 新法术可以被真正研究和创造。

Expansion 负责：

- 研究；
- 原型；
- 实验；
- 稳定；
- 新 Spell Instance 产生流程。

## 53.5 魔法工艺与魔具

World Pack 提供：

- 魔具社会；
- 标准化产业；
- 材料经济背景。

Expansion 负责：

- 制造；
- 修理；
- 附魔；
- 工坊；
- 正式 Item Generation Intent。

## 53.6 主题魔法

World Pack 提供世界允许的领域背景。

Theme Expansion 决定具体：

- Spell Definitions；
- 资源；

# 55. Definition / Instance 不变量

## 55.1 World Pack

定义：

> 埃瑟维亚世界是什么。

不保存：

> 某一局埃瑟维亚现在发生了什么。

## 55.2 Character Card

定义：

> 一个可复用人物是谁。

人物进入游戏后形成 Character State。

## 55.3 Spell Definition

定义：

> 一个标准法术是什么。

角色学会、失去、改造或研究法术属于 Game State / Game Instance。

## 55.4 神性连接

神与凡人的通用关系规则由 Expansion / Runtime 实现。

某角色当前与哪个神连接属于 Game State。

## 55.5 自创法术

游戏中创造的新法术不能静默写回安装的 Expansion。

# 56. World Pack 运行时需求登记

> [!note] 以下是创作暴露的平台需求，不代表当前 Runtime 已经实现。

## WR-MAG-01｜World Definition / Runtime Definition 分离
