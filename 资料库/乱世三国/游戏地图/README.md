# 乱世三国｜游戏地图

这里保存《乱世三国》游戏地图的**当前规范、制图数据、考据证据与美术产出**。

> Root is map; subfolders are depth.

## AI Start Here

第一次进入本目录时，默认按以下顺序读取：

1. [`AGENTS.md`](AGENTS.md) —— 确认 Owner、写入边界与传播规则。
2. [`00_当前规范/游戏地图美术核心规范.md`](00_当前规范/游戏地图美术核心规范.md) —— 理解整套地图的产品与美术原则。
3. 如果任务针对 Level 1 天下总图，再读 [`00_当前规范/天下地理总图制图规范.md`](00_当前规范/天下地理总图制图规范.md)。
4. 只读取任务需要的 [`01_制图数据/`](01_制图数据/) Owner。
5. 只有需要追溯“为什么这样定 / Gate 是否通过”时进入 [`02_考据与审核/`](02_考据与审核/)。
6. 图片、母版和后续正式输出进入 [`03_产出/`](03_产出/)。
7. [`99_归档/`](99_归档/) 默认不进入初始上下文。

不要一次性读取整个目录。

## Current-only

当前规范和持续维护的数据 Owner 使用**稳定路径原位更新**。不要再新增：

- `*_CURRENT_2.md`
- `最终版2.md`
- `最新版.md`
- `v0.2/v0.3` 平行 current 文件

版本演进由 Git history 和 frontmatter `version` 记录；只有具备独立追溯价值的旧工作件才进入 `99_归档/`。

Gate / Review 与图片产出例外：它们本身是过程证据或版本化产物，可以按 Gate、日期、输出版本保留多份，但**不成为 current 规则 Owner**。
