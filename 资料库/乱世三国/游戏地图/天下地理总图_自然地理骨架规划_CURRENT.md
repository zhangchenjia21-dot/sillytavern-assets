# 乱世三国｜天下地理总图自然地理骨架规划 CURRENT

## 0. 职责

本文件负责 `GEO-2｜自然地理骨架`：在不进入正式美术风格和文字排版之前，先冻结天下总图应该遵循的海岸、山地、盆地 / 平原、水系、湖泽结构。

本阶段不生成正式带文字地图。

核心原则：

> **现代地貌图提供稳定地形骨架；历史地理资料负责纠正会随时间显著变化的河道、湖泽和三角洲。**
>
> **不能把现代中国水系图直接描成汉末三国地图。**

# 2. 自然地理对象分成三类

## 2.1 A 类｜天下尺度基本稳定，可直接建立骨架

在 2K 天下尺度上，可主要依据现代地形与可靠历史地理校正：

- 秦岭；
- 太行山系；
- 阴山；
- 祁连山；
- 燕山；
- 岷山；
- 巴山 / 大巴山系；
- 巫山；
- 武陵山系；
- 五岭 / 南岭体系；
- 四川盆地；
- 关中平原；
- 成都平原；
- 华北平原的大范围地势；
- 河西走廊；
- 汉中盆地；
- 江汉平原的大范围低地；
- 长江中下游低平地区。

这类对象允许中国山水式艺术化，但**走向、屏障关系和盆地开口不能由 AI 重画**。

## 2.2 B 类｜主干大体稳定，但局部历史形态需要校正

- 长江干流；
- 汉水；
- 渭水；
- 汾水；
- 泾水；
- 洛水；
- 淮水；
- 湘水；
- 沅水；
- 赣水。

天下尺度可以依据现代主干做几何底子，但涉及：

- 冲积平原河段；
- 河口；
- 湖口；
- 三角洲；
- 历史城市附近河道；

时必须再做历史校正。

## 2.3 C 类｜不能照现代地图，必须历史重建

重点包括：

- **黄河下游**；
- **济水**；
- 云梦泽；
- 彭蠡泽及赣江—大江汇流区域；
- 洞庭湖 / 荆江—洞庭水网的汉末形态；
- 长江三角洲与吴郡东部海岸；
- 黄河入海口及渤海西南岸三角洲；
- 其它因历史淤积、改道而显著变化的湖泽 / 河口。

这类对象如果没有完成历史处理，宁可暂用结构示意，也不得拿现代轮廓冒充汉末事实。

# 3. 一级山地骨架

## 3.1 西北—关中屏障

### 祁连山

- 决定河西走廊南缘；
- 山脉应连续、有明显体量，但不能像卫星浮雕一样布满碎纹理；
- 河西城市应位于走廊北 / 中部可通行带，而不是压到山脊上。

### 秦岭

天下总图最重要的一级自然屏障之一。

必须清楚表达：

- 关中在北；
- 汉中在南；
- 雒阳—南阳方向在其东侧；
- 蜀北道路通过少数山地通道进入汉中 / 巴蜀。

秦岭视觉权重高于普通行政边界。

### 陇山—陇右山地

用于解释：

- 关中向凉州 / 天水方向的地形收束；
- 祁山、陇右诸战的自然背景。

不需要在标准图上写满山名，但地貌必须成立。

## 3.2 河北—并州屏障

### 太行山系

必须作为明显的南北向山地屏障：

- 并州 / 太原在西；
- 冀州平原在东；
- 井陉等通道只有在这条山脉存在后才具有空间意义。

第二张概念图中太行不能被拆成无方向的碎山。

### 阴山

承担北疆空间边界与河套北缘的地形解释。

### 燕山

用于幽州北部 / 东北方向地形层级；在天下图中不需过分突出，但应避免东北地区完全成为无结构平原。

## 3.3 巴蜀—荆襄

### 四川盆地周缘

必须明确表达“盆地感”：

- 成都平原不能被山体碎纹理覆盖；
- 蜀北、蜀东、蜀南山地形成包围；
- 江州、鱼复沿长江上游走廊向东连接三峡。

### 大巴山 / 巴山

解释汉中与巴蜀东北部之间的屏障。

### 巫山

必须与三峡长江河道绑定表达，而不是独立装饰山名。

## 3.4 荆南—岭南

### 武陵山系

表现荆州西南的山地层次，不能让武陵郡看起来与洞庭 / 长沙处在同一无差别平原。

### 五岭 / 南岭

是荆扬南部与岭南 / 交州之间的重要天下级自然屏障。

标准图可使用一个总括性山地带，不必把所有岭逐条标出。

# 4. 一级盆地 / 平原 / 走廊

下一张无字结构图必须能在不看文字的情况下读出以下地形单元：

1. **河西走廊**：狭长、北有荒漠 / 北山背景、南有祁连山；
2. **关中平原**：渭水贯穿，北南受山地约束；
3. **汉中盆地**：秦岭与巴山之间的小型东西向盆地；
4. **四川盆地 / 成都平原**：西南大盆地核心；
5. **华北平原**：冀州—兖州—豫州—徐州核心的广阔低地；
6. **江汉平原**：襄阳以南、江陵—江夏之间的低平水网区；
7. **洞庭—湘江低地区**；
8. **鄱阳 / 赣江低地区**；
9. **长江下游江淮—江东低地区**。

平原区域应是后续文字的主要承载空间，因此视觉上要保持安静，不铺满细碎纹理。

# 5. 一级水系路径

## 5.1 黄河｜必须采用“东汉大河”策略

这是 GEO-2 最重要的历史纠偏。

王莽始建国三年（11年）黄河在魏郡大决，长期泛流；东汉永平十二年（69年）王景治河后形成较稳定的新道。相关水利 / 地方资料指出，**东汉大河自今河南濮阳一带向东北，经鲁西北，随后向东北至今山东滨州—利津方向入渤海**，与今天从山东中部偏北横贯东营入海的现代黄河线路不能机械等同。

因此天下图执行：

```text
黄河上游 / 河套 / 晋陕峡谷 / 关中北缘
→ 参考现代主干 + 历史校正

河南—山东下游
→ 专门重建“东汉大河”
→ 不描现代1855年以后形成的下游河道
```

黄河下游绘制时还要保留它与濮阳、东郡、冀兖青空间关系的合理性。

## 5.2 长江

天下尺度主干总体稳定，可由现代地形 / 水系建立基础路径，但必须重点检查：

- 江州—鱼复—三峡；
- 江陵—江夏 / 夏口；
- 柴桑—彭蠡泽区域；
- 九江—庐江—丹阳—吴郡下游；
- 长江口和三角洲不得使用现代上海地区完整成陆后的海岸轮廓。

## 5.3 汉水

汉水是天下图叙事价值极高的一级水系。

必须明确连接：

```text
汉中方向
→ 上庸附近山地
→ 襄阳 / 樊城空间
→ 江夏 / 汉水入江区域
```

其视觉权重应高于普通二级支流。

## 5.4 淮水

淮水承担豫州—徐州—九江 / 江淮之间的空间分界与交通认知。

标准图必须保留，但不要把后世黄河南徙、夺淮造成的河道状态带回汉末。

## 5.5 渭水

渭水负责关中内部结构：

- 长安；
- 关中平原；
- 向东接黄河；
- 关中东部关隘 / 通道。

应画得明显但次于黄河 / 长江。

# 6. 二级历史高价值水系

## 6.1 济水｜历史水系，不能用现代河名替代

两汉三国时期济水仍是中原—山东重要水系。历史地理研究根据《水经》复原：济水自成皋附近由黄河分出，东经荥泽、阳武、封丘、济阳、定陶方向，入巨野泽，再东北经东平 / 济南方向继续东行。

因此：

- 如果标准图保留“济水”，必须按历史路径绘制；
- 不能用现代地图上不存在的河流状态导致玩家误以为这是虚构水系；
- 它是解释兖州 / 青州西部历史空间的重要辅助线。

## 6.2 汾水

作为太原—河东空间的重要水系，可保留。

## 6.3 泾水 / 洛水

用于强化关中内部与雒阳周边地理结构；其中洛水必须避免与现代洛河名称 / 支流关系混乱。

## 6.4 湘水 / 沅水 / 赣水

用于荆南、扬州西南的区域认知。天下图不画完整支流网，只保留能够解释长沙、武陵、豫章等区域的主要干线。

# 7. 湖泽处理

## 7.1 云梦泽｜画“湖沼平原系统”，不画一个现代大湖

历史研究明确区分“云梦”与“云梦泽”：云梦是广阔地域概念，云梦泽只是江汉平原内的一部分湖沼；汉以后随着泥沙沉积逐步缩小、分解。

天下图策略：

- 不画成一个轮廓明确、像现代洞庭湖一样的大湖；
- 在江陵—江夏之间使用**低湿地 / 湖沼群 / 水网纹理**表达；
- 如果标字，使用“云梦泽”但视觉上让玩家理解它是泽国，而非单一湖盆。

## 7.2 彭蠡泽｜禁止直接画现代鄱阳湖轮廓

历史研究指出，秦汉时期彭蠡泽与后世鄱阳湖的范围 / 形态不能简单等同；秦汉彭蠡水体更偏北部，现代鄱阳湖向南 / 东南扩展是后来的长期地貌演变结果。

天下图策略：

- 使用“彭蠡泽”历史表达；
- 不直接描现代鄱阳湖完整葫芦形湖岸；
- 重点表现赣水北上、湖泽 / 湿地汇聚后与大江相接的空间关系。

## 7.3 洞庭湖｜历史湖区需弱化现代固定岸线

洞庭区域历史演变快。第一版天下图不追求某一年精确湖岸：

- 使用洞庭水域 + 湖沼 / 洲汊的组合表达；
- 湖岸线应比现代地图更“历史水网化”、更柔性；
- 不画现代行政地图式硬边界湖形。

## 7.4 震泽 / 太湖

可以作为江东高价值水域存在，但标准图是否直接写“震泽（太湖）”待 TXT-1 决定。

# 8. 海岸线与三角洲

## 8.1 总原则

天下图不需要古海岸达到考古 GIS 精度，但以下区域不能照现代轮廓：

- 黄河三角洲；
- 长江三角洲；
- 大型河口冲积平原。

## 8.2 渤海西南岸

黄河入海口随历史河道迁移并持续造陆。东汉王景治河后，黄河向滨州—利津方向入渤海，形成古代三角洲；现代黄河三角洲则主要是更晚河道演变后的结果。

因此：

- 不复制今天东营黄河口的突出扇形；
- 海岸应更内收 / 更古朴；
- 东汉黄河入海关系优先于现代岸线。

## 8.3 长江三角洲

长期以来长江三角洲不断向海推进。汉末江东海岸与今天上海—江苏沿海的现代成陆范围不同。

天下图第一版策略：

- 不必复原每条古海岸沙冈；
- 但江东东部海岸整体应比现代图更内收；
- 不让现代上海东部广阔陆地成为汉末默认事实；
- 长江口采用更宽阔的河口 / 潮滩过渡。

# 9. GEO-2 输出分层

正式进入无字结构图时，应拆成可检查的图层：

```text
GEO_COAST
  海岸 / 岛屿 / 大型河口

GEO_RELIEF_MAJOR
  一级山脉 / 高原边缘

GEO_RELIEF_SECONDARY
  二级山地 / 丘陵

GEO_LOWLAND
  平原 / 盆地 / 走廊

GEO_RIVER_MAJOR
  黄河 / 长江 / 淮水 / 汉水 / 渭水

GEO_RIVER_SECONDARY
  汾 / 泾 / 洛 / 济 / 湘 / 沅 / 赣等

GEO_WETLAND
  云梦泽 / 洞庭水域 / 彭蠡泽等
```

下一次结构图只允许使用这些图层，不允许出现：

- 州郡名；
- 城名；
- 关隘名；
- AI 伪文字；
- 势力颜色。

# 10. 下一张无字结构图的验收点

真正生成 / 绘制 `v001-A 地理结构图` 时，Owner 只需要审核：

1. 中国整体轮廓有没有被 16:9 横向拉坏；
2. 河西—关中—汉中—巴蜀层级是否正确；
3. 太行是否真正隔开并州与冀州平原；
4. 四川盆地是否有清楚盆地感；
5. 黄河下游是不是**东汉大河**而不是现代黄河；
6. 汉水是否正确连接汉中—襄阳—江夏方向；
7. 江陵—江夏区域是否有江汉湖沼感；
8. 彭蠡泽是否避免现代鄱阳湖硬套；
9. 长江三角洲 / 黄河三角洲是否避免现代岸线直接复制；
10. 整体是否足够干净，为后续约120–140个信息对象留出空间。

# 11. 当前结论

`GEO-2` 不再是“拿现代水系图让 AI 画古地图”，而是：

> **稳定山地用现代地形建立骨架；稳定主干河流做历史校正；黄河下游、济水、湖泽和三角洲单独历史重建。**

完成 GEO-1 剩余 A 级点位处理与本文件中的关键历史水系路径后，即可制作第一张真正有审核价值的**无字地理结构图 v001-A**。
