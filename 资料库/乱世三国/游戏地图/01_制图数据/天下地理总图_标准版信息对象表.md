# 乱世三国｜天下地理总图标准版最终信息对象表 CURRENT

## 0. 决策

本表把此前约 152 个宽候选收敛成第一轮 2K 全屏标准版的正式信息预算。

目标不是行政百科，而是：

> **在 2560×1440 全屏状态下，保持第二张概念图附近的信息密度，同时优先保证地理正确、具体地点有用、文字清晰。**

正式排版仍允许因局部碰撞在同一优先级内微调，但不得重新扩大候选池。

---

# 1. 州级｜13｜全部进入标准版

司隶、豫州、冀州、兖州、徐州、青州、荆州、扬州、益州、凉州、并州、幽州、交州。

州名是最大尺度区域标题，不代表需要把所有州界画成现代政治地图式硬边界。

# 3. 城市 / 具体地点｜标准核心 30 + 扩展 9

## 3.1 标准核心｜30

雒阳、长安、邺、许、蓟、涿、襄平、陈留、濮阳、谯、宛、新野、下邳、彭城、寿春、广陵、襄阳、江陵、成都、南郑、江州、吴县、秣陵、柴桑、合肥、姑臧、敦煌、晋阳、番禺、临湘。

说明：

- `许` 默认不写成现代“许昌”；
- `吴县` 优先于单写“吴”，避免与吴政权概念混淆；
- `秣陵` 为时期敏感名，正式 TXT-1 前再次核显示名；
- `襄平 / 濮阳 / 南郑 / 合肥 / 姑臧` 已有明确区域型历史锚，不允许 AI 自行落点；
- `夏口` 不作为这一组固定城市点，见第 4 节。

## 3.2 标准扩展｜9

阳翟、阆中、鱼复、上庸、皖、山阴、临淄、绵竹、平原。

实际标准版城市 / 地点建议落位约 `35–39` 个。局部碰撞时，优先保留具体城市而非重复郡名。

## 3.3 高信息 / 区域备用

平舆、公安以及后续区域图真正需要的次级城邑。

# 4. 关隘 / 战略 / 著名事件节点｜标准目标 9–12

## 4.1 标准核心候选

官渡、赤壁、夷陵、祁山、武关、井陉、定军山。

这些对象即使不是行政城市，也显著帮助玩家理解三国 Narrative 的空间结构。

## 4.2 名称 / 关址核定后再进入标准版

函谷关、潼关、成皋 / 虎牢、阳平关、剑阁 / 剑门。

这些对象的**战略通道本身可以进入无字地理骨架**，但正式关隘图标和文字必须等单点历史名称 / 关址核定后再加入。

## 4.3 中立总图不强制画固定城市点

夏口：保留“汉水—长江汇合口战略区域”的空间权重；TXT-1 再决定是否显示“夏口”。

白帝 / 白帝城：标准版可优先由已经锁定的`鱼复`承担三峡西端空间锚；是否另外显示白帝留给高信息版或时期明确的地图。

葭萌：优先留给区域图；不强制写成“葭萌关”。

# 5. 自然地理文字｜标准目标 22–25

## 5.1 一级河流｜5｜全部保留

黄河、长江、淮水、汉水、渭水。

## 5.2 二级河流｜标准优先 7

汾水、泾水、洛水、漳水、湘水、沅水、赣水。

`济水`历史价值高，但路径历史化工作复杂；在路径未可靠重建前不为了数量硬塞标准版，可进入高信息版。

## 5.3 一级山地 / 屏障｜8

秦岭、太行山、祁连山、阴山、巫山、五岭 / 南岭、泰山、岷山。

巴山可以在地貌中明显存在，文字是否加入由排版决定。

## 5.4 湖泽 / 大型水域｜4–5

洞庭湖、彭蠡泽相关历史水域、震泽（太湖）、云梦泽湿地区域；巢湖如实际排版有余量再加入文字。

注意：`云梦泽`是复合湿地 / 湖沼概念；`彭蠡泽`不得直接按现代鄱阳湖巨大轮廓表现。

# 7. 排版冲突的最终删减顺序

发生局部碰撞时：

```text
高信息备用
→ 标准扩展郡国
→ 标准扩展次级地点
→ 标准扩展专题节点
→ 重复行政标签
```

最后才考虑删除：

- 一级山河；
- 标准核心城市；
- 标准核心州 / 郡；
- 对空间理解不可替代的战略节点。

禁止通过把所有字号一起缩小到难读来“解决”碰撞。
