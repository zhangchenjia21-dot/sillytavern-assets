# 乱世三国｜关中—弘农—雒阳区域地图输入

## 0. Pilot 目标

首张 Level 2 Pilot 用于验证：

- 天下图视觉 DNA 是否能自然下沉到区域尺度；
- 城市—道路—关隘—山河能否形成清楚的旅行空间；
- 区域图是否能增加生活痕迹而不变成行政百科；
- Level 2 是否可以使用简化流程，不重复 Level 1 全套 Gate。

本图的 Narrative 主轴：

> **长安 → 渭水 / 关中平原 → 弘农 / 崤函通道 → 雒阳**

同时测试秦岭北缘、黄河、武关方向与关中东出门户的表达。

---

# 1. R0｜范围与玩家问题

玩家应能理解：

1. 长安为什么处于关中平原与渭水体系中；
2. 关中为什么受秦岭与黄河 / 山地约束；
3. 长安向雒阳的东向交通为何集中于有限通道；
4. 弘农为什么是关中—雒阳之间的重要过渡空间；
5. 武关等南向通道为什么能改变区域交通选择。

初始语义范围：

- 西：保留长安及关中西部必要背景，不继续展开整个凉州；
- 东：覆盖雒阳及其东侧少量缓冲，不扩展完整中原；
- 北：保留黄河、河东 / 山地关系所需背景；
- 南：保留秦岭北麓及武关方向必要山地，不深入完整汉中 / 南阳地图。

实际裁切由 R3 Artwork Space 再确定，不直接用经纬矩形硬切。

# 2. R1｜直接继承 Level 1

## 2.1 核心城市

| 名称 | Level 1 状态 | 本区域职责 |
|---|---|---|
| 长安 | LOCKED | 关中核心城市 / 西部主要锚 |
| 雒阳 | LOCKED | 东部核心城市 / 司隶东端 Narrative 锚 |

其它已存在 Level 1 城市如实际落入裁切范围，只继承其历史 identity，不为填图强制加入。

## 2.2 一级自然地理

必须继承：

- 渭水；
- 黄河；
- 秦岭；
- 关中平原；
- 弘农—雒阳方向山河过渡关系。

不得改变：

- 长安位于秦岭北侧、渭水体系内；
- 雒阳位于长安以东；
- 秦岭继续承担南北屏障；
- 关中东出必须体现受山河与门户控制，而不是一块无障碍大平原。

# 3. R2｜本区域新增对象 Backlog

本节只列需要核验 / 筛选的对象类别，不在证据不足时伪造精确点。

## 3.1 高优先级关隘 / 门户

- 函谷关：需按当前地图采用的历史阶段核具体关址 / 显示名；
- 潼关：时期与关址需核，不直接以现代景区点代替；
- 武关：Level 1 已作为战略节点存在，区域图需深化通道关系；
- 成皋 / 虎牢方向：是否进入本 Pilot 由东侧裁切范围和历史名称核定决定。

## 3.2 候选次级城市 / 地点

后续只纳入对旅行、政治、交通或 Narrative 真正有价值的对象。

优先从现有 historical data / CHGIS / 地方遗址资料核：

- 弘农区域的高价值城邑；
- 关中主要交通节点；
- 雒阳周边与崤函通道直接相关的地点。

不为行政完整性填入全部县邑。

## 3.3 道路需求

至少需要验证三类交通：

1. 长安—弘农—雒阳主轴；
2. 关中向南经武关方向的通道；
3. 黄河 / 山地约束下的北侧辅助交通。

正式道路节点、渡河点与支线必须在历史 / 地形证据后再锁定。

# 4. R3｜Regional Artwork Space

## 4.1 需要放大的空间

- 长安与关中平原；
- 弘农 / 崤函过渡区；
- 雒阳及其西侧门户；
- 武关方向的南向分岔。

## 4.2 可压缩空间

- 与主 Narrative 无关的西部边缘；
- 黄河北部低价值背景；
- 秦岭深山区非交通空间；
- 雒阳以东仅作背景的中原空间。

## 4.3 绝不能改变

- 长安—雒阳东西顺序；
- 渭水—关中—秦岭关系；
- 主要通道受山地 / 河流控制；
- 武关方向作为南向门户而非随机山中节点。

---

# 5. R4｜地方性格

视觉关键词：

> **关中沃野 / 渭水平原 / 秦岭北麓 / 崤函险道 / 帝都与驿路**

区域图可比天下图增加：

- 更明确的田野与农业带；
- 河谷、浅丘和山麓层次；
- 驿道与交通节点；
- 城郭和少量聚落；
- 关隘的地形门户感。

避免：

- 满屏建筑；
- 现代道路网；
- 把秦岭画成连续无缺口巨墙；
- 为古意加入重度旧纸效果。

# 6. R5｜Pilot 信息预算

首轮只使用“够验证模板”的信息量。

必须：

- 长安、雒阳；
- 渭水、黄河、秦岭；
- 长安—弘农—雒阳主交通轴；
- 至少 1–2 个已核高价值关隘 / 门户；
- 少量真正必要的次级城市 / 地点。

可选：

- 次级河流；
- 渡河点；
- 山道；
- 农田 / 聚落生活痕迹。

第一张 Pilot 不追求区域内容完整版。

# 7. 当前 Blocker / 下一动作

在正式生图前需要完成一次最小区域数据补齐：

1. 锁定 Pilot 最终裁切范围；
2. 核函谷 / 潼关 / 成皋—虎牢在本图时期中立策略下的显示方式；
3. 选出少量区域级次级城邑；
4. 建立长安—弘农—雒阳及武关方向的道路控制点；
5. 再进入 R3 / R4 构图和美术。

原则：

> **只补首张 Pilot 真正需要的数据，不先建立整个司隶县级数据库。**
