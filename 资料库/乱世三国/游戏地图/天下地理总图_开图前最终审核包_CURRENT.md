# 2. 坐标与投影硬规则

## 2.1 禁止经纬度矩形直接拉伸成 16:9

工作流程：

```text
历史经纬度 / 遗址区域
→ 统一 Albers 工作投影
→ 保持几何比例
→ 等比装入 16:9
→ 最后才做受控制图偏移
```

工作投影：

```text
Albers Equal Area Conic
lon_0 = 105°E
lat_1 = 25°N
lat_2 = 47°N
WGS84
```

这是美术定位工作基线，不是 Runtime GIS Contract。

## 2.2 画布

- 玩家审阅：`2560 × 1440`
- 源母版目标：`7680 × 4320`
- 16:9 优先
- 不为“铺满屏幕”横向拉伸大陆
- 投影主体可以自然留下左右海域 / 边疆空间

## 2.3 点、区域、文字必须分离

### 点

城市、具体城邑、战役点、明确关隘等使用历史锚点。

- `LOCKED`：符号按点位绘制；
- `ANCHORED`：在可信历史区域内允许小幅微调；
- `ANCHORED-REGION`：用区域约束，不冒充古城中心点；
- `PERIOD-SENSITIVE`：按地区 / 语义处理，不强制成为固定城市点；
- `PROVISIONAL`：不进入正式点位图。

### 区域

州 / 郡不是“郡治坐标”。区域文字应根据行政空间、山河边界与空白区摆放。

### 文字

文字可以排版偏移；真实地理锚点不能为了文字方便被任意搬走。

# 3. GEO-2 自然地理最终前置规则

## 3.1 可以主要继承现代稳定地貌骨架的对象

天下尺度可主要依据现代高程 / 地形骨架再艺术化：

- 秦岭
- 太行山系
- 祁连山
- 阴山
- 巴蜀盆地周缘
- 巫山 / 三峡山地
- 五岭 / 南岭体系
- 四川盆地
- 汉中盆地
- 关中平原
- 华北 / 中原主要平原
- 江汉平原的大尺度低地位置
- 河西走廊地形夹持关系

这里继承的是**山地与低地的拓扑关系**，不是现代卫星图视觉。

## 3.2 必须历史校正的黄河

汉末总图不能照现代山东黄河画。

王景治河后的东汉下游采用历史控制关系：

```text
河南濮阳南 / 西南附近
→ 范县南
→ 莘县东 / 阳谷西一带
→ 茌平南 / 东阿北一带
→ 鲁西北低地
→ 利津方向
→ 渤海
```

因此：

- 东汉下游整体比现代黄河口体系更偏北 / 东北历史河道；
- 现代黄河三角洲突出部不能直接进入汉末海岸；
- 濮阳与东汉大河之间的相对关系必须正确。

## 3.3 长江

主河谷大尺度稳定，但江汉平原和三角洲必须避免现代工程化形态。

控制关系：

```text
巴蜀东部
→ 鱼复
→ 三峡
→ 夷陵
→ 江陵 / 荆江
→ 汉水入江区域
→ 柴桑 / 九江方向
→ 江淮南缘
→ 丹阳 / 吴郡方向
→ 汉末古海岸
```

荆江在汉末应允许分流、洲滩与湖沼感，不能画成今天受堤防控制的规则单槽。

## 3.4 汉水

```text
汉中盆地
→ 上庸方向山地
→ 襄阳
→ 江汉平原
→ 汉水—长江汇合口
```

汉水是天下图的一级叙事水系，视觉权重高于普通支流。

## 3.5 淮水与渭水

淮水：保持豫南—江淮—东部低地的东西水系骨架，不在第一版画满所有现代支流。

渭水：明确表现关中平原与秦岭北麓关系；长安必须处于正确的渭水—关中空间。

## 3.6 二级河流

第一版允许：

- 汾水
- 泾水
- 洛水
- 漳水
- 湘水
- 沅水
- 赣水

`济水` 继续作为历史高价值但复杂的高信息对象；除非路径单独核到足够可靠，不在标准无字结构底稿中用一条现代同名河道替代。

## 3.7 云梦泽

不得画成一个大而边界清楚的现代湖泊。

表达方式：

> **江汉平原低地 + 湖沼 + 水网 + 湿地 + 洲滩。**

“云梦”与“云梦泽”不能混为一整片统一大湖。

## 3.8 洞庭湖

保留重要水域认知，但使用古代湖群 / 洲滩感，不逐像素描现代洞庭湖岸。

## 3.9 彭蠡泽

不能直接画成现代鄱阳湖轮廓。

汉末策略：

- 九江—柴桑—湖口附近保留重要历史水域；
- 南侧大片现代鄱阳湖区域明显克制；
- 赣江下游以低地 / 河网进入北部水域；
- 不使用今天完整鄱阳湖形状。

## 3.10 海岸线

以下区域必须历史化：

- 长江三角洲 / 上海—太仓方向：现代外伸陆地不能完整复制；
- 黄河三角洲：现代黄河口与现代三角洲不能复制；
- 珠江三角洲：汉代应显著更海湾化、水域化，番禺古城附近珠江宽度也远大于今日同段。

其他以基岩海岸为主的区域可在天下尺度主要参考现代轮廓，再做适度简化。

# 5. 2K 标注排版规则

## 5.1 视觉读取顺序

玩家打开全屏地图时，应先读到：

```text
天下山河 / 大地形
→ 州级区域
→ 核心城市
→ 重点郡国
→ 次级城市 / 战略节点
→ 二级自然地理
```

不能让 132 个文字对象在视觉上同时喊话。

## 5.2 文字层级建议｜2560×1440 初始测试值

以下为**初始排版测试区间**，不是最终字体 Contract；字体风格确定后仍需真实 2K 预览微调。

| 类别 | 2K 初测字号 | 说明 |
|---|---:|---|
| 州 | 42–54 px | 最大区域层；可有较强古意，但必须清晰 |
| 核心郡国 | 24–30 px | 阅读性优先 |
| 核心城市 | 22–26 px | 配城市符号，不能被郡名吞没 |
| 次级城市 / 地点 | 18–22 px | 标准版最低主要阅读层 |
| 战略 / 关隘 | 18–22 px | 与城市符号区分 |
| 一级河流 | 22–28 px | 沿河排字，可适度字距 |
| 二级河流 | 18–22 px | 低于一级水系 |
| 一级山地 | 22–30 px | 沿山势，但不可压住城镇 |

标准版原则：

> **正式可读文字尽量不低于约 18 px 的 2K 实际显示高度。**

如果一个对象只有把字缩到不可读才能存在，应降到高信息版 / 区域图，而不是牺牲整张地图的清晰度。

## 5.3 字体使用原则

正式文字：

> **100% 现代简体中文显示字形。**

- 州名可以较有书法 / 题签气质；
- 郡、城市、关隘中小字号优先高辨识度，不使用狂草或难认字形；
- 历史专名保留历史名称，但字形使用简体；
- 现代地名只存在于研究 / 映射记录，不默认上正式图。

最终具体字体名称暂不冻结；在视觉风格样张阶段选择。

## 5.4 AI 中文硬禁令

正式地图文字不得由图像生成模型直接画进底图。

禁止：

- AI 生成州名；
- AI 生成郡名；
- AI 生成城市名；
- AI 生成河山名；
- AI 生成仿汉字装饰；
- AI 伪造印章文字作为正式信息。

所有正式文字使用真实字体 / 可编辑文字层后置。

## 5.5 城市标签偏移

- 城市符号锚点服从历史位置；
- 标签优先在点位周围 `8–32 px` 范围寻找空位；
- 极端高密度区可扩大到约 `48 px`，必要时用非常克制的引线；
- 不允许为了标签美观把城池符号跨河、跨山或搬到错误郡域。

## 5.6 州 / 郡标签

州 / 郡为区域文字：

- 放在区域可读中心，而非州治 / 郡治点；
- 可以为城市、河流和山口主动让位；
- 大州名可跨较大留白面，但不应覆盖大量城市图标；
- 郡名不能密集铺成行政志。

## 5.7 高碰撞区

必须单独做 2K 局部碰撞测试：

1. 长安—弘农—雒阳
2. 雒阳—陈留—许—颍川
3. 邺—魏郡—冀州南部
4. 濮阳—东郡—黄河历史河道
5. 徐州—寿春—合肥—广陵
6. 宛—新野—襄阳—江陵—江夏
7. 成都平原北缘—汉中南侧
8. 柴桑—九江—庐江—丹阳—吴郡

碰撞解决顺序：移动区域文字 → 调整文字对齐方向 → 降级低价值标签 → 最后才考虑删除核心对象。

- 如果某次生成只达到概念图级分辨率，则它只进入参考阶段，不伪装成最终资产。

# 11. 资料依据与不确定性边界

## 11.1 核心空间点位

主要使用：

- CHGIS / 复旦 TGAZ 时空地名辞典：`https://tgaz.fudan.edu.cn/tgaz/`
- 各地官方 / 文保 / 遗址资料
- 用户提供的 `三国州郡总图.jpeg` 经纬 / 行政空间参考

具体状态保存在点位坐标表中。

## 11.2 东汉黄河

参考水利史资料对王景河的历史路径描述：东汉王景治河后的下游从今濮阳附近分流，经范县、莘县 / 阳谷、茌平 / 东阿等方向，至利津入渤海。

参考：

- `https://slt.nx.gov.cn/slxc/jswm/wxwh/202407/t20240731_4610537.html`
- `https://slj.weihai.gov.cn/art/2020/10/27/art_2632_2424837.html`

本项目只需要天下尺度可信路径，不声称复原每一处古堤线。

## 11.3 云梦 / 荆江

中国历史研究院对《中国自然地理·历史自然地理》的介绍明确指出：`云梦` 与 `云梦泽` 范围概念不同，云梦泽位于江汉平原内；先秦两汉荆江存在分流 / 三角洲阶段。

参考：

- `https://hrczh.cass.cn/sxqy/zgs/202502/t20250228_5853600.shtml`

## 11.4 彭蠡 / 鄱阳湖

历史地理研究显示现代鄱阳湖并非可以直接回投到汉代；汉代相关水域与河网远比现代湖体复杂，现代大湖范围有长期历史演变。

参考：

- `https://www.nopss.gov.cn/n1/2021/0906/c219544-32218615.html`
- `https://www.cctv.com/geography/special/changjiang/20040607/101390.shtml`

## 11.5 长江三角洲

上海 / 长江口地区长期向海成陆；尤其现代浦东外伸部分形成较晚，因此汉末不能直接复制现代长江口海岸。

参考：

- 上海地区成陆历史地理研究：`https://iqh.ruc.edu.cn/old/zglsdlyj/lsdl_lzjj/xszm/e8baae39568441f488ebf34d517de86d.htm`
- 上海通志相关成陆资料：`https://www.shanghai.gov.cn/shanghai/newshanghai/上海通志.pdf`

## 11.6 珠江 / 番禺

广州官方历史地理资料根据秦代船台、南越国宫署、水闸等考古资料指出，秦汉番禺城附近珠江宽度约 2 km，明显比今日同段更宽；今番禺南部很多区域古时为海湾 / 洲岛环境。

参考：

- `https://www.gz.gov.cn/zlgz/whgz/content/post_8125326.html`
- `https://www.gz.gov.cn/zlgz/whgz/content/post_9196337.html`
