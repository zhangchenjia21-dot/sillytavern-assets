# 乱世三国｜天下地理总图核心点位坐标表 CURRENT

## 0. 职责

本文件是天下总图的**点位事实工作表**。它只负责具体城市 / 城邑 / 关隘 / 战略节点的空间锚点，不负责州郡文字排版，也不让图像生成模型自行决定地点位置。

硬规则：

> **历史坐标先于美术构图。**
>
> **符号锚点可以锁死，文字标签可以偏移。**
>
> **资料不足时标记不确定，不伪造精确度。**

---

# 1. 定位状态

- **LOCKED**：已有 CHGIS / TGAZ、官方遗址或等价高可信资料支持，可进入 GEO-3 点位测试图。
- **ANCHORED**：历史城址所在现代区域可靠，但当前引用的精确点可能来自后世同址治所或遗址中心；足以约束大方向，正式点位图前仍可微调。
- **PROVISIONAL**：名称、时期、关址或具体点位仍有明显争议；不得直接进入正式点位图。

状态描述的是**制图确定度**，不是历史重要性。

---

# 2. 工作投影与 2K 草图框

统一采用空间规划文件中的 Albers Equal Area Conic 工作投影：

```text
proj = aea
lon_0 = 105°E
lat_1 = 25°N
lat_2 = 47°N
WGS84
reference extent = 85°E–131°E / 17°N–43°N
```

2K 草图框：

```text
canvas = 2560 × 1440
projected body ≈ 2020 × 1280
origin ≈ (270, 80)
```

`U / V` 为投影参考范围内归一化位置；`2K X/Y` 仅用于当前排版草图，正式事实源仍是历史经纬度 / 投影坐标。

# 5. 关隘定位：必须先分清“历史关”与“现代景区”

## 5.1 函谷关｜PROVISIONAL，禁止直接用灵宝景区点

当前资料明确存在至少两套需要区分的历史空间：

- **秦函谷关 / 函关古道**：今河南灵宝一带，灵宝市政府与三门峡市政府均有遗址 / 古道资料；
- **汉函谷关遗址**：全国重点文物保护单位，位于河南省新安县东关村。

对于汉末三国地图，不能因为现代知名景区在灵宝，就自动把“函谷关”图标钉到灵宝。下一步必须核实东汉末具体文献中的“函谷关”主要对应哪一处关址 / 通道，再确定标准图是否：

1. 标汉函谷关；
2. 标“崤函”通道而弱化具体关名；
3. 或同时保留历史关址差异到高信息版。

这是本轮最重要的关隘定位警示案例。

## 5.2 武关｜ANCHORED

陕西文物资料列有**武关城遗址（战国）**，位于丹凤；相关历史考察资料明确武关镇、武关河及“长安—蓝田—武关—襄阳”的武关道。

当前足以锁定**武关通道与丹凤武关镇区域**，但正式图标仍应对准古城墙 / 古道关系，而不是现代镇政府中心。

## 5.3 井陉｜ANCHORED AS CORRIDOR

河北省文物局确认井陉古驿道古关隘（东天门等）为全国重点文保相关对象；地方资料显示井陉古道承担太行东西交通。

天下图应优先把**井陉理解为太行山通道 / 陉口区域**，而不是硬缩成一个现代“井陉关景区”点。

## 5.4 剑阁 / 剑门｜ANCHORED AS CORRIDOR

四川省相关规划资料明确：三国时期剑阁境内已有汉德县、连云古柏驿道等历史空间，后世“剑门”建制名称出现更晚。

天下图第一阶段应锁定**大剑山—剑阁道—蜀北门户的通道位置**；最终显示“剑阁”“剑门”还是关隘图标，需要结合汉末 / 蜀汉用名继续核。

## 5.5 暂不锁点

以下仍需专门考证，不因现代同名景区而直接落图：

- 潼关
- 成皋 / 虎牢
- 壶关
- 阳平关
- 葭萌

# 6. 当前 GEO-1 进度

已获得可用于约束空间的核心城市：

- LOCKED：至少 21 个；
- ANCHORED：至少 5 个；
- 仍需核验的高价值城市：约 14 个。

关隘方面已经建立正确方法，但还没有达到“全部可画正式图标”的程度。

GEO-1 的通过标准仍然是：

> **A 级具体地点的大多数符号位置都有历史依据，剩余不确定点有显式状态；不存在需要图像模型凭感觉补位置的核心点。**
