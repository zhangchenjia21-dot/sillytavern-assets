# 乱世三国｜天下地理总图制图规范

## 0. 当前目的

本文件是 Level 1 天下地理总图当前制作的 Rule Owner，负责冻结下一张正式地图生成前必须遵守的制图、构图、文字、美术与 QA 规则。

从本文件开始：

> **不再边生成图片边临时决定历史位置、文字和信息层级。**

> **天下总图不是“中国自然地理图换一种画风”，而是以可信历史地理为骨架、为《乱世三国》叙事与游戏使用重新设计的世界地图。**

生成顺序固定为：

```text
GEO-1 核心点位
→ GEO-2 自然地理骨架
→ VIS-1 无字美术底图
→ GEO-3 城市 / 关隘符号测试
→ TXT-1 真实简体文字排版
→ 标准版 / 高信息版
```

# 1. 画布、世界范围与空间方法

## 1.1 玩家审阅目标

- 16:9 全屏 GUI；
- 核心审阅分辨率：`2560 × 1440`；
- 任何字体和信息密度判断最终以 2K 实际尺寸为准。

## 1.2 美术母版

建议 `7680 × 4320` 或同等 16:9 高分辨率可编辑源。

## 1.3 地理参考几何

禁止把经纬度矩形直接整体横向拉伸到 16:9。

事实层仍使用统一投影建立参考骨架：

```text
历史地理坐标
→ 同一 Albers Equal Area Conic 工作投影
→ 获得可信参考骨架
```

工作投影：

```text
proj = aea
lon_0 = 105°E
lat_1 = 25°N
lat_2 = 47°N
WGS84
```

该投影承担**事实定位与校准**，不等于最终玩家看到的地图必须保持 GIS 式严格比例，也不定义游戏 Runtime Contract。

## 1.4 天下总图正式世界范围

本图不展示“完整中国及其西部高原 / 西域”的自然地理全貌，而只保留对汉末三国叙事有实际价值的天下范围。

正式构图范围：

- **西：到凉州 / 河西走廊，保留敦煌—酒泉—张掖—武威方向；敦煌以西只允许少量荒漠 / 远山作为世界边缘，不继续展开西域；**
- **西南：保留益州、南中及其必要山地背景，不展开大片青藏高原；**
- **北：保留并州、幽州北缘及少量塞外环境，不把大面积北方草原当画面主体；**
- **东：到辽东半岛及必要渤海 / 海域背景，不继续扩展朝鲜半岛等非当前核心空间；**
- **南：完整覆盖岭南与交州，至少保证番禺、交趾方向存在足够空间；**
- **东南海域只保留构图需要的海面，不以展示整个东亚海域为目标。**

这是一条**游戏世界构图边界**，不是新的历史行政疆界。

画面边缘不得像 GIS 截图一样硬切：

- 西部以荒漠、戈壁、远山渐隐；
- 西南以大山、云气、雾霭自然收束；
- 北部以草原、荒地、山带渐隐；
- 南部以山地、海岸和少量环境延伸收束；
- 东部主要由海域形成天然边界。

## 1.5 参考投影之后允许“受控叙事性制图形变”

上一阶段“统一投影后等比装入 16:9”只适合作为**事实校准层**，不再作为最终美术构图的唯一几何要求。

最终玩家地图允许在参考骨架上进行**局部、受控、拓扑保持的叙事性形变**：

- 关中—雒阳—中原可以适度舒展；
- 荆襄可为南阳—新野—襄阳—江陵—江夏提供更多可读空间；
- 江淮—江东可为寿春、合肥、广陵、丹阳、吴郡、会稽提供更多排版空间；
- 巴蜀应让四川盆地、成都平原、汉中与巴东的关系清晰可读；
- 河北南部等高密度叙事区允许获得比严格地理比例更大的视觉面积。

但必须满足：

1. 东西南北关系不反转；
2. 高价值城市的事实锚点关系不被随意重排；
3. 河流汇流、山脉屏障、盆地围合与区域邻接保持可信；
4. 不通过全图统一拉宽 / 拉高制造空间；
5. 形变服务叙事、标注和玩家认知，不服务装饰。

原则：

> **真实地理决定拓扑骨架；游戏地图决定视觉面积分配。**

# 2. 空间对象定位方法

## 2.1 城市 / 具体地点

城市符号首先是历史地理事实点：

- `LOCKED`：使用历史点位；
- `ANCHORED`：允许在可信历史区域内微调；
- `ANCHORED-REGION`：使用区域锚，不冒充考古测绘级中心点；
- `PERIOD-SENSITIVE`：不强行固定为中立地图的永久城点。

图像生成模型没有重新决定城市位置的权限。

进入叙事性制图形变后，应通过统一的局部变换映射事实锚点，而不是让单个城市脱离周围山河单独搬家。

## 2.2 州 / 郡国

州和郡国是**区域标签**，不是郡治点。

郡名位置依据：

```text
区域范围
+ 邻接关系
+ 山河屏障
+ 核心城邑
+ 可读性空白
```

郡名可以为城市让位；这种文字移动不代表行政范围改变。

## 2.3 文字

正式文字是独立排版层，可从符号锚点偏移。必要时使用克制的引线，但不得把城池本身挪到错误位置来配合文字。

# 3. 自然地理硬约束

## 3.1 一级水系

必须遵守已经冻结的控制关系：

- 黄河；
- 长江；
- 淮水；
- 汉水；
- 渭水。

### 黄河特别规则

汉末下游采用王景治河后的**东汉大河**空间逻辑。

东汉王景治河后，黄河下游从濮阳附近向东北，经今范县、鲁西北、滨州方向，至利津附近入海。不得把现代山东黄河下游直接复制进汉末地图。

## 3.2 二级水系

汾水、泾水、洛水、漳水、湘水、沅水、赣水进入第一轮结构图。

济水继续作为历史敏感路径，不在缺少可靠复原时硬描。

## 3.3 山地

至少明确：

- 秦岭；
- 太行山系；
- 祁连山；
- 阴山；
- 巴蜀盆地周缘；
- 巫山—三峡；
- 五岭 / 南岭；
- 岷山等高价值山地。

山脉走向由地理骨架决定，图像模型只负责绘画语言，不得自由发明走向。

## 3.4 湖泽

- 云梦泽：画作江汉平原湖沼 / 水网 / 湿地复合系统，不画一个封闭巨湖；
- 洞庭湖：保留高价值大水域，但古湖群岸线不照现代逐像素复制；
- 彭蠡泽相关区域：汉代水域明显不能直接套现代鄱阳湖南扩后的轮廓；
- 震泽 / 太湖：可保留大尺度水域，岸线适度简化。

## 3.5 海岸

基岩海岸可以现代几何为辅助，但以下冲积区必须历史化：

- 长江三角洲；
- 黄河三角洲；
- 珠江三角洲。

汉末这些区域应比现代更水域化 / 海湾化或更内收，不使用现代围垦、现代三角洲突出部作为古代事实。

# 4. 游戏化构图与空间排版

## 4.1 视觉重心

核心高密度带：

> **关中—河北—中原—荆襄—巴蜀—江淮—江东**

这条核心世界应占据画面的主要视觉面积。凉州、辽东、交州必须存在，但不得像完整中国自然地理图那样让大片低叙事密度背景抢走主体面积。

## 4.2 六个重点碰撞区

必须单独审：

1. 长安—弘农—雒阳；
2. 邺—冀州南部；
3. 陈留—濮阳—许—颍川—汝南；
4. 徐州—寿春—合肥—广陵；
5. 宛—新野—襄阳—江陵—江夏；
6. 秣陵—吴郡—会稽—柴桑 / 豫章方向。

## 4.3 空间优先权

发生碰撞时：

> **高价值具体地点 > 低价值行政完整性。**

例：`南阳郡` 与 `宛 / 新野` 发生冲突，优先保证宛、新野符号和文字清楚，南阳郡标签可移动或弱化。

## 4.4 留白是主动设计资源

平原不等于“没画完”，而是给后续游戏信息和文字留下的核心空间资源。

- 不使用满屏碎山填空；
- 不使用大量装饰村落填空；
- 不因为边疆标签少就强行增加冷门行政名；
- 为后续清晰文字保留安静背景；
- 平原可以有极轻的田野、河漫滩、浅丘、林地色差，但不得变成连续噪声。

## 4.5 地貌必须承担“游戏空间角色”

天下图中的自然地理不能只是高程纹理。

### 山脉

一级山脉可以适度夸张体量，使玩家直接读懂其空间作用：

- 秦岭：关中—汉中的大屏障；
- 太行：并州 / 上党—河北平原的屏障；
- 巫山 / 三峡：巴蜀—荆州的峡江门户；
- 五岭 / 南岭：荆南—岭南的屏障；
- 祁连：塑造河西走廊。

二级山地承担地区性格；普通丘陵只轻描，不满屏堆砌。

### 河流

河流的视觉等级按**叙事与空间认知价值**而非现代水文等级机械分配。

- 黄河、长江是天下骨架；
- 汉水必须比普通现代水系图中更醒目，因为它承担“汉中—上庸—襄阳—江夏”的 Narrative 轴；
- 淮水、渭水等承担明确区域结构；
- 次级河流降低对比度。

原则：

> **山河不是背景纹理，而是玩家理解路线、屏障、门户和区域关系的地图角色。**

## 4.6 区域应有可辨识的环境性格

即使没有任何文字，玩家也应通过地貌、色彩和水系感到区域正在变化：

- 凉州：更干燥、赭黄，河西呈狭长绿洲 / 走廊感；
- 关中：山地围合的宽阔沃野，渭水贯穿；
- 河北 / 中原：开阔、低平、农耕与河网感；
- 荆襄：水陆交错、植被更浓，汉水—长江关系明显；
- 巴蜀：盆地内部温润开阔，周缘山地强；
- 江东：河湖、水网、低丘交错；
- 交州：更湿润、更绿、更具南方气候感。

区域差异必须保持统一艺术语言，不能变成七张不同风格地图的拼贴。

# 5. 正式中文文字规范

## 5.1 简体硬约束

正式游戏地图：

> **100% 使用现代简体中文显示字形。**

历史专名保持历史名称，但使用其正常简体字形。

图像生成模型产生的繁体、异体、伪汉字不进入正式资产。

## 5.2 AI 文字禁令

无字地图生成阶段禁止出现：

- 州名；
- 郡名；
- 城市名；
- 关隘名；
- 河山名；
- 仿汉字装饰；
- 伪书法铭文。

所有正式文字由真实字体单独渲染。

## 5.3 2K 字级基线

最终字体尚待风格参考确定，第一轮排版用以下**显示尺寸测试区间**，不是固定最终字号：

| 层级 | 2K 测试字号 | 设计原则 |
|---|---:|---|
| 州级 | 34–44 px | 可有一定书法气质，但必须一眼能读 |
| 郡国 | 20–25 px | 以清晰、稳定为主 |
| 核心城市 | 20–24 px | 与城市符号形成明显组合 |
| 次级城市 / 关隘 | 17–20 px | 2K 正常观看距离可直接辨识 |
| 山河 | 18–24 px | 沿地形排布，颜色 / 字形区别于行政文字 |

正常标准版不建议使用小于约 `16 px` 的正式中文标签来解决拥挤。

## 5.4 字体方向

- 州名允许最强传统气质；
- 郡和城市不用狂草 / 过度书法化字体；
- 小字号优先高辨识度宋 / 楷 / 明朝体类方向；
- 最终具体字体等 Owner 的视觉风格参考确定后再锁。

# 6. 城市 / 关隘符号规范

第一轮只需要一套统一、克制的符号语言：

- 都城 / 天下级核心城：最高一档；
- 重点郡治 / 大城：第二档；
- 普通高价值城邑：第三档；
- 关隘：与城市明确不同；
- 战役 / 战略地点：不能误读成行政城市。

符号必须比早期概念图更简洁，避免花哨圆环、复杂城墙图标造成视觉噪声。

GEO-3 先只测试符号，不加文字。

# 7. VIS-1 无字底图视觉规范

## 7.1 总方向

> **高质量三国游戏世界地图 + 中国传统舆图 / 山水艺术语言 + 可信历史地理骨架。**

评价顺序：

> **游戏世界地图感 > 传统山水语言 > 资料图 / 自然地理图感。**

严禁把现代中国地形 / relief map 换成米黄色、青绿色或古风笔刷后直接作为天下图。

## 7.2 底材

允许：

- 干净的浅暖米白 / 绢本色；
- 极弱纸绢纤维；
- 很轻的自然色差。

禁止：

- 大面积泛黄；
- 霉点；
- 污渍；
- 折痕；
- 破损边；
- 强颗粒；
- 随机墨污。

## 7.3 色彩

主体使用低至中饱和的自然传统色：

- 温润米白；
- 墨青 / 灰青；
- 石青 / 石绿；
- 赭石；
- 灰蓝。

地图不能整体灰黑，也不使用永久战争红调。

颜色用于塑造区域地貌与气候，不通过大片政治色块划分区域。

## 7.4 地貌密度

- 一级山脉明确而有角色感；
- 二级山地克制；
- 平原保持大块安静面；
- 普通丘陵不铺成满屏碎山；
- 海面简洁；
- 河流有明确主次线宽；
- 生活痕迹、道路、村镇等全部延后，不在第一张无字底图里增加噪声。

## 7.5 下一版不是旧图裁剪

新的范围决定要求**重新设计构图**。

不得把此前“完整中国自然地理”版本简单裁掉青藏高原 / 西域后继续使用。核心三国区域必须重新放大、重新分配视觉面积、重新组织山河层级，使它从第一眼就是“乱世三国的天下”，而不是“被裁剪的中国地形图”。

# 8. 下一张图片的唯一任务

下一次真正生成 / 制作的图定义为：

> **GEO-2 / VIS-1 之间的“16:9 无字天下地理底图 v002”。**

只允许包含：

- 按本规范收缩后的三国世界范围；
- 历史化海岸；
- 游戏化重构但拓扑可信的山脉 / 山地；
- 盆地 / 平原；
- 黄河、长江、淮水、汉水、渭水；
- 高价值二级水系；
- 湖泽 / 湿地；
- 区域环境性格所需的基础地貌色彩。

禁止包含：

- 任何文字；
- 城市图标；
- 关隘图标；
- 州郡线；
- 势力色；
- 道路；
- 军队 / 旗帜；
- GUI；
- 装饰性印章 / 题签；
- 做旧效果；
- 大片青藏高原 / 西域；
- 与三国世界无关的大面积东亚背景。

下一次审核回答三个问题：

1. **世界范围和视觉重心对不对？**
2. **地理拓扑与山河关系对不对？**
3. **它是否真正像一张干净的三国游戏世界地图，而不是自然地理资料图？**

# 9. 下一张图 QA Checklist

任何一项关键失败都不进入文字阶段。

## 9.1 世界范围 / 构图

- [ ] 西界止于凉州 / 河西走廊，敦煌以西只有少量边缘环境；
- [ ] 没有大片青藏高原抢占画面；
- [ ] 东界到辽东半岛，未无意义扩展整个东北亚；
- [ ] 南界覆盖交州，岭南不是被压成画布边缘的一条细带；
- [ ] 关中—河北—中原—荆襄—巴蜀—江淮—江东构成明确视觉主体；
- [ ] 地图不是旧版完整中国地形图的简单裁切；
- [ ] 四周边缘通过荒漠、远山、海域、云气等自然收束，而非硬截断。

## 9.2 地理结构

- [ ] 地图没有通过全局横向拉伸获得 16:9；
- [ ] 河西走廊自然夹在祁连山与北部荒漠之间；
- [ ] 关中由秦岭 + 渭水 + 黄河共同成立；
- [ ] 太行山正确分隔并州 / 上党与河北平原；
- [ ] 汉中盆地位于秦岭以南、巴蜀北缘；
- [ ] 四川盆地内部明显比周边山地开阔；
- [ ] 三峡段具有明显山峡空间；
- [ ] 江汉平原能够看出汉水入江与湿地系统；
