# 乱世三国｜区域地图制图规范

## 0. 定位

本文件是 Level 2 区域地图 Rule Owner。

区域图不是把天下图机械放大，而是帮助玩家理解一个地区如何生活、旅行、通行、阻隔并发生故事。

原则：

> **继承 Level 1 已冻结的事实与视觉成本，只补区域级信息。**

## 1. 继承链

```text
Level 1 历史 / 地理事实
→ Level 1 已确认的相对空间关系
→ 本区域新增考据
→ Regional Artwork Space
→ 区域美术与文字
```

不得重新决定已锁核心城市、一级山河和关键邻接关系。只有发现明确新证据时才回到对应 Data Owner 修正。

## 2. Fact Space / Regional Artwork Space

Fact Space 负责历史点位、山河拓扑、交通事实、行政与时代信息。

Regional Artwork Space 负责最终画布、视觉面积、道路可读宽度、标签安全区和环境叙事强化。

区域图允许比天下图更强的局部游戏化形变，但必须保持：

- 山河两侧关系；
- 城市和道路拓扑；
- 关键门户；
- 区域出入口；
- 相邻地点顺序。

## 3. 视觉 DNA

必须继承 Level 1：

- 温润米黄 / 淡绢色底；
- 墨青、灰绿、赭石山体；
- 石青 / 灰蓝水系；
- 低至中饱和；
- 古意而不做旧；
- 真实简体中文；
- 同源城市、聚落、关隘、道路、渡口与地标符号语言。

区域图允许增加山水绘卷感、林地、湿地、农田、水乡、城郭和聚落，但不能变成卫星图、现代 GIS、SLG 彩色行政沙盘或泛奇幻 RPG 地图。

## 4. 区域差异

地方性格来自真实地理与生活方式，不来自装饰：

- 关中：渭水、平原、秦岭北麓、驿道、关口；
- 荆襄：汉水、江汉湿地、渡口、湖沼；
- 巴蜀：盆地、山道、剑阁 / 三峡门户；
- 江东：江河湖网、水乡、丘陵、港口；
- 河北：大平原、太行东麓、北方交通轴；
- 凉州：走廊、戈壁、绿洲、山前通道。

## 5. 信息优先级

```text
核心城市 / 高价值地点
> 关隘 / 渡口 / 交通节点
> 主道路与河流
> 次级城市 / 聚落
> 山岭 / 湖泽 / 地标
> 必要行政标签
> 装饰
```

区域图不做行政百科，不要求显示所有郡县。

## 6. 城市与新增地点

Level 1 已有城市继承 identity 与大尺度关系，只映射到新的 Regional Artwork Space。

新增县邑 / 聚落至少满足一项：Narrative 高频、政治经济价值、交通转折、历史事件、渡口港口山谷入口或玩家空间认知不可替代。

不要为了填空机械增加县邑。

## 7. 道路与交通

Level 2 正式承担道路表达。

道路用于说明城市如何连通、哪些路穿山、哪些路线沿河、哪些关口控制交通。

建议分为：一级主干、二级道路、少量高价值山道 / 栈道。

禁止现代公路线型、直线穿山、无渡口语义跨越大河、把所有可能道路全部画出。

水路地区应同时表现高价值渡口 / 港口，但不使用现代航线 UI。

## 8. 文字与画布

- 正式文字使用真实简体中文字体；
- 城市、聚落、关隘、渡口、山河有不同层级；
- 标签可偏移，不移动事实节点；
- 必要时使用短、克制 leader line；
- 默认 16:9，Pilot 审阅 `2560×1440`；
- 保留无字底图、标准标注版与可编辑 Overlay。

## 9. 简化流程

Level 2 不重复天下图完整 Gate 链。

```text
R0 范围与 Narrative 目标
→ R1 继承 Level 1 事实骨架
→ R2 补区域点位 / 道路 / 渡口
→ R3 游戏化构图
→ R4 无字区域底图
→ R5 确定性符号与文字
→ R6 QA / Owner Review
```

只有新的高风险事实争议才插入专项考据。

## 10. QA

通过前至少确认：

- 核心城市与 Level 1 关系一致；
- 山河方向可信；
- 道路不穿越不可能地形；
- 关隘 / 渡口控制真实通道；
- 玩家能看懂主要旅行轴；
- 高频地点优先，低价值行政信息没有挤占空间；
- 与 Level 1 属于同一视觉世界；
- 地区性格明确；
- 文字真实可读；
- 第一眼能分辨城市、道路、山河和门户。

## 11. Pilot

首张 Pilot：

> **关中—弘农—雒阳区域图**

用于验证城市、道路、关隘、河流、平原与山区在区域尺度下的统一模板。Pilot 通过后，再以荆襄测试复杂水网和高密度城市。
