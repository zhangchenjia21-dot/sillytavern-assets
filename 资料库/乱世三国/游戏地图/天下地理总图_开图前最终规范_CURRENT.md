# 1. 画布与投影

## 1.1 玩家审阅目标

- 16:9 全屏 GUI；
- 核心审阅分辨率：`2560 × 1440`；
- 任何字体和信息密度判断最终以 2K 实际尺寸为准。

## 1.2 美术母版

建议 `7680 × 4320` 或同等 16:9 高分辨率可编辑源。

## 1.3 地理几何

禁止把经纬度矩形直接横向拉伸到 16:9。

工作流程：

```text
历史地理坐标
→ 同一 Albers Equal Area Conic 工作投影
→ 保持几何比例
→ 等比装入 16:9
→ 受控的视觉排版偏移
```

工作投影：

```text
proj = aea
lon_0 = 105°E
lat_1 = 25°N
lat_2 = 47°N
WGS84
```

该投影只承担美术定位，不定义游戏 Runtime Contract。

# 2. 空间对象的三种定位方法

## 2.1 城市 / 具体地点

城市符号是历史地理点：

- `LOCKED`：使用历史点位；
- `ANCHORED`：允许在可信历史区域内微调；
- `ANCHORED-REGION`：使用区域锚，不冒充考古测绘级中心点；
- `PERIOD-SENSITIVE`：不强行固定为中立地图的永久城点。

图像生成模型没有重新决定城市位置的权限。

## 2.2 州 / 郡国

州和郡国是**区域标签**，不是郡治点。

郡名位置依据：

```text
区域范围
+ 邻接关系
+ 山河屏障
+ 核心城邑
+ 可读性空白
```

郡名可以为城市让位；这种文字移动不代表行政范围改变。

## 2.3 文字

正式文字是独立排版层，可从符号锚点偏移。必要时使用克制的引线，但不得把城池本身挪到错误位置来配合文字。

# 3. 自然地理硬约束

## 3.1 一级水系

必须遵守已经冻结的控制关系：

- 黄河；
- 长江；
- 淮水；
- 汉水；
- 渭水。

### 黄河特别规则

汉末下游采用王景治河后的**东汉大河**空间逻辑。

东汉王景治河后，黄河下游从濮阳附近向东北，经今范县、鲁西北、滨州方向，至利津附近入海。不得把现代山东黄河下游直接复制进汉末地图。

## 3.2 二级水系

汾水、泾水、洛水、漳水、湘水、沅水、赣水进入第一轮结构图。

济水继续作为历史敏感路径，不在缺少可靠复原时硬描。

## 3.3 山地

至少明确：

- 秦岭；
- 太行山系；
- 祁连山；
- 阴山；
- 巴蜀盆地周缘；
- 巫山—三峡；
- 五岭 / 南岭；
- 岷山等高价值山地。

山脉走向由地理骨架决定，图像模型只负责绘画语言，不得自由发明走向。

## 3.4 湖泽

- 云梦泽：画作江汉平原湖沼 / 水网 / 湿地复合系统，不画一个封闭巨湖；
- 洞庭湖：保留高价值大水域，但古湖群岸线不照现代逐像素复制；
- 彭蠡泽相关区域：汉代水域明显不能直接套现代鄱阳湖南扩后的轮廓；
- 震泽 / 太湖：可保留大尺度水域，岸线适度简化。

## 3.5 海岸

基岩海岸可以现代几何为辅助，但以下冲积区必须历史化：

- 长江三角洲；
- 黄河三角洲；
- 珠江三角洲。

汉末这些区域应比现代更水域化 / 海湾化或更内收，不使用现代围垦、现代三角洲突出部作为古代事实。

# 4. 标准版空间排版规划

## 4.1 视觉重心

核心高密度带：

> **关中—河北—中原—荆襄—巴蜀—江淮—江东**

边疆仍完整存在，但不使用相同标签密度。

## 4.2 六个重点碰撞区

必须单独审：

1. 长安—弘农—雒阳；
2. 邺—冀州南部；
3. 陈留—濮阳—许—颍川—汝南；
4. 徐州—寿春—合肥—广陵；
5. 宛—新野—襄阳—江陵—江夏；
6. 秣陵—吴郡—会稽—柴桑 / 豫章方向。

## 4.3 空间优先权

发生碰撞时：

> **高价值具体地点 > 低价值行政完整性。**

例：`南阳郡` 与 `宛 / 新野`发生冲突，优先保证宛、新野符号和文字清楚，南阳郡标签可移动或弱化。

## 4.4 留白

平原的空白属于主动设计资源：

- 不使用满屏碎山填空；
- 不使用大量装饰村落填空；
- 不因为边疆标签少就强行增加冷门行政名；
- 为后续清晰文字保留安静背景。

# 5. 正式中文文字规范

## 5.1 简体硬约束

正式游戏地图：

> **100% 使用现代简体中文显示字形。**

历史专名保持历史名称，但使用其正常简体字形。

图像生成模型产生的繁体、异体、伪汉字不进入正式资产。

## 5.2 AI 文字禁令

无字地图生成阶段禁止出现：

- 州名；
- 郡名；
- 城市名；
- 关隘名；
- 河山名；
- 仿汉字装饰；
- 伪书法铭文。

所有正式文字由真实字体单独渲染。

## 5.3 2K 字级基线

最终字体尚待风格参考确定，第一轮排版用以下**显示尺寸测试区间**，不是固定最终字号：

| 层级 | 2K 测试字号 | 设计原则 |
|---|---:|---|
| 州级 | 34–44 px | 可有一定书法气质，但必须一眼能读 |
| 郡国 | 20–25 px | 以清晰、稳定为主 |
| 核心城市 | 20–24 px | 与城市符号形成明显组合 |
| 次级城市 / 关隘 | 17–20 px | 2K 正常观看距离可直接辨识 |
| 山河 | 18–24 px | 沿地形排布，颜色 / 字形区别于行政文字 |

正常标准版不建议使用小于约 `16 px` 的正式中文标签来解决拥挤。

## 5.4 字体方向

- 州名允许最强传统气质；
- 郡和城市不用狂草 / 过度书法化字体；
- 小字号优先高辨识度宋 / 楷 / 明朝体类方向；
- 最终具体字体等 Owner 的视觉风格参考确定后再锁。

# 6. 城市 / 关隘符号规范

第一轮只需要一套统一、克制的符号语言：

- 都城 / 天下级核心城：最高一档；
- 重点郡治 / 大城：第二档；
- 普通高价值城邑：第三档；
- 关隘：与城市明确不同；
- 战役 / 战略地点：不能误读成行政城市。

符号必须比第二张概念图更简洁，避免花哨圆环、复杂城墙图标造成视觉噪声。

GEO-3 先只测试符号，不加文字。

# 7. VIS-1 无字底图视觉规范

## 7.1 总方向

> **现代高清游戏地图 + 中国传统舆图 / 山水艺术语言。**

不是仿古董纸，也不是现代卫星 relief map。

## 7.2 底材

允许：

- 干净的浅暖米白 / 绢本色；
- 极弱纸绢纤维；
- 很轻的自然色差。

禁止：

- 大面积泛黄；
- 霉点；
- 污渍；
- 折痕；
- 破损边；
- 强颗粒；
- 随机墨污。

## 7.3 色彩

主体使用低至中饱和的自然传统色：

- 温润米白；
- 墨青 / 灰青；
- 石青 / 石绿；
- 赭石；
- 灰蓝。

地图不能整体灰黑，也不使用永久战争红调。

## 7.4 地貌密度

- 一级山脉明显；
- 二级山地克制；
- 平原保持大块安静面；
- 普通丘陵不铺成满屏碎山；
- 海面简洁；
- 河流有明确主次线宽；
- 生活痕迹、道路、村镇等全部延后，不在第一张无字底图里增加噪声。

# 9. 下一张图的 QA Checklist

任何一项失败都不进入文字阶段。

- [ ] 中国主要空间比例没有被为 16:9 横向拉宽；
- [ ] 河西走廊自然夹在祁连山与北部荒漠之间；

- [ ] 太行山正确分隔并州 / 上党与河北平原；
- [ ] 汉中盆地位于秦岭以南、巴蜀北缘；

- [ ] 江汉平原能够看出汉水入江与湿地系统；

- [ ] 辽东、河西、交州等边疆没有被压缩到失真。

## 9.2 水系

- [ ] 黄河山东下游不是现代河道照搬；
- [ ] 黄河东汉下游总体向东北入渤海；
- [ ] 汉水正确经过襄阳方向进入江汉平原；
- [ ] 长江三峡—江陵—武汉—柴桑—江东关系可信；
- [ ] 淮水没有与长江 / 黄河关系画错；

## 9.3 海岸

- [ ] 长江三角洲未直接使用现代上海突出岸线；
- [ ] 黄河口未使用现代三角洲；

## 9.4 美术

- [ ] 没有任何文字 / 伪汉字；
- [ ] 没有明显旧纸污渍、霉点和折痕；
- [ ] 平原有足够安静面；
- [ ] 山体没有满屏碎成噪声；
- [ ] 海面简洁；
- [ ] 河流清楚但不荧光、不抢画面；
- [ ] 2560×1440 下整体仍显得清爽；
- [ ] 风格像高质量游戏世界地图，而不是资料扫描图或卫星图。
